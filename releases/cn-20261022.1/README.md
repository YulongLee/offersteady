## 本地核对与文件恢复

在本标签工作区运行 `python3 -B releases/cn-20261022.1/tools/verify_snapshot.py`，逐SHA核对Backend230、worker196、Web328、Nginx、203接口Schema及模型7键。校验不连接生产，不读取私有配置。

需要离线取回文件时，运行 `restore_snapshot.py --component backend|material-worker|web --output <空目录>`。worker输出独立的 `/app` 相对目录；Web输出 `html/` 与 `nginx/default.conf`。工具拒绝非空输出和不安全归档路径，不调用Docker或修改线上服务；它不会恢复用户数据。公开静态包是网页精确字节来源，整仓前端重新构建不能自动视为线上等价。

`recipes/` 记录各组件固定镜像来源及精确Web增量的镜像构造方法。固定镜像须已在恢复主机可用；Git不包含容器镜像层、生产环境或密钥，因此这些recipe不承诺在全新主机重现相同镜像ID。恢复发布仍需重新核对实际组件、私有配置归属和完整用户工作门禁，不能把历史控制器当作新的发布授权直接执行。
