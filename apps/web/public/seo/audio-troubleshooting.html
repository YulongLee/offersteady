Audio Troubleshooting

面试收音慢、断续或丢字，先按来源排查

实时识别同时依赖本地设备、操作系统权限、会议软件音量、网络传输和转写服务。先判断是“我的声音”还是“面试官声音”异常，再逐项检查，通常比反复重启更有效。

面试收音异常，第一步应该检查什么？

先确认异常来自“我的声音”还是“面试官声音”。麦克风负责候选人声音，电脑输出音频负责面试官声音；伴随程序的两路音量指示可以判断当前是否收到信号。只有一路没有波动时，应优先检查对应设备和权限。

  • 我的声音为 0
    检查麦克风选择、系统麦克风权限、耳机静音和输入音量。
  • 面试官声音为 0
    检查电脑输出通道、会议软件播放设备和系统音频权限。
  • 两路都有但很慢
    检查网络、CPU 占用和会议软件是否同时使用重型降噪。
  • 一直显示转写中
    确认后续语音是否仍推进；必要时暂停后恢复，或改用手动输入。

macOS 与 Windows 权限

macOS

在“系统设置 → 隐私与安全性”中检查麦克风和屏幕与系统音频录制权限。权限修改后通常需要完全退出伴随程序再重新打开。若应用升级或包标识变化，可按使用手册重新授权。

Windows

检查系统“隐私和安全性 → 麦克风”是否允许桌面应用访问；确认会议软件输出设备与伴随程序选择的电脑输出通道一致。蓝牙耳机切换通话模式时，也可能改变采样质量和设备名称。

减少延迟和丢字的实际做法

  1. 优先使用稳定网络，避免同时上传大文件或进行系统更新。
  2. 让会议软件和伴随程序使用明确的输入、输出设备，不频繁自动切换。
  3. 保持面试官播放音量足够，但避免扬声器回声重新进入麦克风。
  4. 出现异常时记录具体时间、哪一路声音和界面状态，便于定位链路环节。

仍未解决：可先使用手动输入继续面试，不要反复点击生成同一问题。联系客服时请勿发送密码、验证码或完整个人资料。
