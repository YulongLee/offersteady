What does the desktop Companion do?

The Companion connects a supported macOS or Windows computer to the active Web workspace with a short connection code. It provides the device-side microphone, supported computer-output audio, and user-triggered screenshot capabilities required by live interview and written-exam workflows.

The Companion does not start a session by itself. Opening the website alone does not begin audio or screen capture. You choose the sources, grant operating-system permissions, and connect the intended session.

Which installer should you choose?

On macOS, choose the installer that matches Apple silicon or Intel hardware. On Windows, use the supported 64-bit installer. The download controls in the application show the currently published release options. Do not install packages copied from an unverified third-party source.

Keep the Companion updated when the preparation page reports that a newer compatible version is available. A stable application identity helps the operating system retain permissions, but macOS and Windows can still require the user to confirm microphone or screen access.

How do you prepare the Companion?

Open it before the interview, select the microphone and computer-output source you intend to use, and confirm that the meters respond. Enter the connection code from the OfferSteady preparation page. If you change a headset or output device, verify the selected route again before continuing.

Start from the Web workspace: create or open the intended interview, continue to preparation, and use the connection code shown there. A successful device connection does not itself start an interview. Review the selected materials and settings before entering the live workspace.

What should you verify on macOS and Windows?

Confirm that the operating system recognises the microphone you selected and that the Companion has the permission required for the feature you intend to use. Screen capture and audio permissions are controlled by the operating system, so a browser permission does not replace a Companion permission.

On any platform, reconnecting a headset can change the active device. Check the microphone and computer-output meters after every device change. If one source is unavailable, do not assume the other source has failed as well; verify them independently.

What can you do if the connection is inactive?

Keep the preparation page open and confirm that the six-digit code belongs to that session. Check network access, the selected sources, and the visible permission state. If the application reports a newer compatible release, use only the verified option shown in the signed-in product.

If audio stops after a device change, reselect the intended route and speak or play a short test while watching the meter. If Screen Assist is the only feature needed, confirm the selected display and capture permission without enabling unrelated audio sources.

Privacy and interview rules

Raw audio is not stored by default. Screenshots are created only when you trigger capture. Follow applicable law and the interview organiser's rules for recording, transcription, screen capture, confidentiality, and AI assistance.

AI output is guidance. Verify every claim, answer from your real experience, and follow the interview organiser's rules.
