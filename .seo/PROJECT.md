# 面试稳 SEO / GEO 项目上下文

- 站点：`https://mianshiwen.cn/`
- 产品：面向求职者的 AI 面试辅助工具
- 市场与语言：中国大陆，简体中文
- 主要用户：需要进行面试准备、现场表达整理和面试后复盘的求职者
- 首要转化：访问公开页面后阅读使用手册或进入手机号登录
- 核心公开事实：可结合简历、岗位 JD 和用户选择的知识材料；提供实时对话整理、手动输入、截图回答和面试复盘；支持 Web、macOS 和 Windows 使用方式

## 不可突破的边界

- 不承诺获得 Offer、回答完全准确、不可检测或与第三方面试平台存在官方合作。
- 不虚构用户评价、客户、排名、流量、转化、准确率、效率提升、法律主体或统计口径。
- AI 输出只作为建议，个人经历和项目结果必须以用户真实情况为准。
- 不在公开页面暴露提示词、模型配置、个人资料、验证码、支付密钥、内部接口或测试用户数据。
- 不改变登录、面试、实时收音、截图、资料、计费、支付、桌面助手或 API 行为。
