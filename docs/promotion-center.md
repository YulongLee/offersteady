# 推广中心数据口径与运行边界

状态：Local development，生产采集默认关闭

## 固定口径

- 报表时区：`Asia/Shanghai`。
- 获客归因窗口：首次注册前 30 天。
- 第一方匿名访客 Cookie：90 天；仅在用户未退出非必要分析时设置。
- 原始推广触点：180 天；聚合快照可长期保存，但不得包含可识别个人的信息。
- 主漏斗“使用”：用户首次成功开始实时面试。桌面助手绑定只作为诊断指标，不替代主漏斗阶段。
- 默认漏斗 Cohort：所选期间首次有效推广访问的访客，并在 30 天观察窗内观察后续转化。

## 指标定义

| 指标 | 服务端定义 |
| --- | --- |
| 有效访问 | 页面可见达到阈值、通过 Bot/预览/内部流量过滤的 `qualified_visit` |
| 有效 UV | 选定范围内按匿名 visitor HMAC 去重的有效访问人数 |
| 注册 | `auth_users.created_at_ms` 权威事实，且注册时完成确定性推广认领 |
| 下载 | 服务端实际返回或重定向到已发布桌面安装包后的后台记录；按钮点击不算下载 |
| 使用 | `interview_sessions.started_at_ms` 存在的首次实时面试 |
| 下单 | `billing_checkout_orders.created_at_ms` 权威事实 |
| 支付 | 支付渠道权威确认且本地订单状态为 `paid` |
| 推广贡献实收 | 已归因 paid 订单的 `amount_cents` 之和，不等同净利润 |
| 注册率 | 归因注册用户 / 有效 UV |
| 激活率 | 首次使用用户 / 归因注册用户 |
| 付费率 | 付费用户 / 归因注册用户 |
| CAC | 已录入推广成本 / 付费用户 |
| ROAS | 推广贡献实收 / 已录入推广成本 |
| ROI |（推广贡献实收 - 已录入推广成本）/ 已录入推广成本 |

成本缺失时 CAC、ROAS、ROI 必须返回 `null` 并展示“成本未录入”，不能用 0 或无穷大代替。渠道、活动、链接报告使用同一日期、时区、归因模型和版本。

## 归因规则

- `first_touch` 选择注册前窗口内最早的有效推广触点。
- `last_non_direct_touch` 选择注册前窗口内最后一个有效推广触点。
- 获客归因只在首次注册后的短暂认领窗口内锁定。老用户后续点击只可作为辅助触点，不得改写获客来源。
- 每个 `conversion_type + authoritative source_record_id + model + model_version` 只能有一条归因事实，避免重复计算订单和收入。
- 无法证明来源的记录保持 `direct`、`organic` 或 `unattributed`，不得生成虚假推广来源。

## 隔离与开关

`OFFERSTEADY_PROMOTION_ENABLED` 默认是 `false`。关闭时：

- 管理员会话不获得推广权限，后台不展示推广中心。
- `/r/{slug}` 只安全跳转到产品首页，不设置推广标识。
- 普通 Web 访问不发起有效访问请求；注册后的归因认领失败被静默忽略。
- 下载、注册、面试、ASR、快答、截图、下单和支付能力不依赖推广数据库、Redis Stream 或分析任务。

开启后，跳转事件进入有界 Redis Stream，由独立 `offersteady-promotion-analytics` 任务写入推广表、派生权威转化和生成聚合快照。队列或任务失败只把报表标记为延迟/不完整，不回滚用户操作。

## 隐私字段边界

允许的访问字段只有随机事件 ID、服务端 HMAC 后的 visitor/click、推广链接 ID、时间、站内目标枚举、referrer host、设备大类和过滤结果。禁止进入推广事件、分析表和普通日志的内容包括手机号、验证码、密码、访问令牌、原始 IP、完整 UA、完整 referrer URL、资料、音频、转录、截图、问题和回答正文。

退出非必要分析不得阻止跳转、注册、下载、面试或支付。账号删除完成时，用户绑定与用户级转化必须删除或不可逆解绑，只保留非识别聚合。公开隐私政策须在正式启用生产采集前完成合规复核并同步更新；当前本地开发不会改变线上数据处理声明。
