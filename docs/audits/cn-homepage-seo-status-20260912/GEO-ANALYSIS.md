- 首页直接定义“面试稳是一款面向求职者的AI面试助手”，包含是什么、如何工作、适合岗位、收费、设备和使用边界等 8 个问答。

- sitemap.xml 返回 200，包含 30 个 URL，四个核心页均在内。本次没有逐一检查全部 30 个 URL 的状态。
- robots.txt 返回 200，通配爬虫允许抓取；GPTBot、OAI-SearchBot、ChatGPT-User、ClaudeBot、PerplexityBot 明确 Allow。robots 允许不代表真实爬虫一定会访问，也不排除不同网络路径上的 WAF 限制。
- llms.txt、llms-full.txt、public-facts.json 均返回 200。
- 首页 JSON-LD 包含 Organization、WebSite、SoftwareApplication；三张子页包含 WebPage、BreadcrumbList。此处为类型与可解析性检查，不代表通过富结果资格校验；解析器给 @graph 外层的 Unknown 不是节点错误。
- 线上公开价格页原始 HTML 有 10 项金额。重新执行候选构建的 verify-pricing-live.mjs 通过：10 个商品与实时生产目录一致，快照小于 24 小时；该脚本验证的是候选构建，并非为线上价格快照的全部权益逐项复核。

## 本地与生产的区别

- local layout-preview.html 故意使用 noindex,nofollow、合成数据，不用于收录。
- 候选正式 dist/index.html 没有这个限制，保留 SEO 元信息和正文。
- 生产没有本地新增的场景区文案；本次排版版本仍未上线。不能将本地视觉修改描述成线上已生效。
- 生产首页仍有“当前价格以登录后页面为准”的旧段落；本地新版已通过公开价格入口改善。发布时应将可见内容、静态 HTML 和公开事实同步核对。

2. 在既有 FAQ、功能和专题内补足真实场景的直接答案、步骤和自然内链；不批量造页，不虚构评价或竞品事实。
3. 对获批候选做生产构建及发布前价格检查；发布后重新检查原始 HTML。部署需另行确认。
4. 根据百度收录/曝光数据和真实 AI 引用样本决定下一批内容，而非仅凭关键词数量。

GEO 不等于添加特定文件。Google 官方说明：AI Overviews/AI Mode 没有额外技术要求或特殊 schema 要求，重要内容可读、可索引和与结构化数据一致仍是基础；满足条件也不保证收录与展示。该说明仅适用于 Google，不能替代对国内 AI 搜索产品的实测。[官方来源](https://developers.google.com/search/docs/appearance/ai-features)
