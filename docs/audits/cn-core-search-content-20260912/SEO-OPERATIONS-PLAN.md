# 国服 SEO/GEO 迭代计划

## 目标与基线

业务目标是让有真实面试辅助需求的求职者找到正确页面，理解能力和费用，完成有效下载、注册与使用。不是单纯增加关键词数量，也不保证超过全部竞品。

本地基线：此前新版首页 + 30 个现有公开页面。核心索引标记已建立；本轮改善四页内容与机器可读事实。百度当前索引量、曝光、点击、排名和自然转化均未知，历史“索引为 0”不是当前状态结论。

## 内容路线与执行顺序

1. 用户本地验收本轮四页，保留首页总体风格。
2. 单独处理既有回归测试与公共入口性能问题，同时取得搜索数据。
3. 改善手册的初始 HTML 一致性；根据真实搜索词判断哪些现有技术专题需要补充案例或说明。
4. 获准发布后重新核验动态价格、生产响应和主要入口。本文未授权或安排自动发布。
5. 有可靠竞品数据后再讨论比较页，不先批量建页或生成模板文章。

## 观测与复查

上线当天核对版本、价格、五页双 UA、sitemap、资源和真实404。随后每周以相同维度查看已索引页数、抓取错误、核心查询曝光点击、落地页点击率；积累至少一个可比较的28天窗口后再判断趋势，控制品牌词、季节和渠道变化。曝光先变不等于转化改善。

GEO 使用固定问题样本（是什么、适合哪些岗位、如何工作、如何收费、怎么下载），记录模型/日期/地区/回答与引用 URL，核对是否误述价格和产品能力；小样本仅用于发现问题，不作为市场份额或排名证据。

当前未创建监控自动化、未读取私有统计、未部署；需要数据或下一批实现时由用户确认。
