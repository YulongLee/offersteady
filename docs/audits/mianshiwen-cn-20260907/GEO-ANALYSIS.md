# 国服 GEO 小结

基础已具备：30 个 sitemap 页面有独立 HTML；robots 和 llms 文本已存在；部分深度专题有定义、表格、来源、团队和日期。

主要缺口：隐私/协议的无 JS 正文、公开价格事实、待核验经营主体、产品实测截图，以及品牌在外部真实渠道上的可核对资料。性能/发布兼容问题先处理，避免新流量遇到加载失败。

准备度：待改善，数值评分数据不足。百度 AI、豆包、元宝、DeepSeek、Kimi、Google AI、ChatGPT、Perplexity 各自的实际引用率均未测，不能填分或推断排名。未做 Wikipedia/Reddit 等外部覆盖分析，不推荐为刷存在感创建不符合规则的条目。

没有“安装一个 GEO 文件就上榜”的保证。Google 官方说明可见于 [AI features](https://developers.google.com/search/docs/appearance/ai-features)：仍遵循 SEO 基础，不需要特殊 AI 文件或 schema；该说明不代表其他平台内部规则。
