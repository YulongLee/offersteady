# 国服 SEO / GEO 执行清单

本清单来自 [审计证据](FULL-AUDIT-REPORT.md)，只规划、未实施或部署。时间为建议排期，不是排名见效承诺。

## 第一批：用户可用性（先于引流，P0）

| 工作 | 验收 | 风险边界 |
|---|---|---|
| 保留旧版不可变静态资源 | 上一版打开的标签页在新版上线后可继续进入各功能，不请求 404 脚本 | 只加回对应资源，不能覆盖当前入口文件/混装 HTML；限制保留周期 |
| 首页与业务状态加载解耦 | API 延迟 15 秒或失败时，主标题、功能、开始/下载入口仍可见；动态价格不伪造 | 不改变受保护工作台初始化、鉴权、计费、面试状态 |
| 非首屏视频/图片延迟 | 冷缓存移动端首屏请求不包含非必要媒体；视频滚入后能播放、开声音/全屏 | 不重新编码或移除音轨，不增加新追踪 |

先记录冷/热缓存、匿名/已登录、手机/桌面、弱网四类基线，区分 HTML TTFB、脚本、接口等待、可见首屏。指标目标必须基于可复现实验，不拿单次 curl 当整站验收。发布仍需用户授权与空闲检查。

## 第二批：技术与商业信息（P1，建议一周内）

1. `/terms`、`/privacy` 输出真实独立正文、title、description、H1、canonical，法律内容与客户端同源维护。评审后决定索引策略；登录/工作台继续 noindex。
2. `/pricing` 从现有正式商品目录生成公开价格快照，带最后同步时间及发布失效规则；不得写死另一份价格。价格变更要联动重建/刷新；先明确管理后台变更如何触发同步。
3. 确认国服实际运营主体。历史提供的“杭州临平知界智能技术工作室（个体工商户）”只作待确认候选，不能自动拿国际站主体替换国服合同主体。统一 About、Contact、法律页及 Organization，邮箱保留 contact@oneshowailab.com。
4. 统一主域跳转（非 www 已是 canonical），先验证路径/参数/推广链接/登录 Cookie 和 API 客户端，避免一个 SEO 跳转影响业务。
5. 修正首页 sitemap lastmod，其他页面只在实质更新后修改日期；保留现有 30 个 URL。
6. CI + 公网发布验收：sitemap URL 均 200、独立 title/H1/self-canonical、HTML 非空、法律页不回首页、未知页真实 404、旧资源可取、生产构建版本匹配。

## GEO 具体执行

- 对每页选择 2～4 个关键问题：第一句直接给结论，之后给条件、步骤和例外；不追求固定英文字数。
- 文章标注真实维护团队、实测版本/日期、可核对来源；不编造履历、评分或用户反馈。
- 现有 llms 文件继续维护，与正文事实一致；不把新增文件、放开训练爬虫视为排名开关。
- 以同一品牌主页连接真实运营的公众号/知乎/B站/小红书等官方账号（如确实存在并由用户提供），发布对应真实教程，不刷外链、不伪装第三方推荐。
- 初始 10 个观察问题：面试稳是什么；支持哪些系统；如何收费；Mac 如何授权；腾讯会议无转写怎么排查；面试资料如何准备；简历和 JD 如何结合；项目经历怎么讲；RAG 面试如何准备；AI 辅助有哪些使用边界。
- 每周在用户实际关注的 AI 搜索产品手工记录联网回答、日期、来源 URL、品牌准确性。不声称可以保证推荐，不将单次回答当平台排名。

## 需要用户补充（不需要密码）

1. 百度资源平台最近 30 天：索引量趋势、流量与关键词（展现/点击/位置如有）、抓取异常、代表 URL 的抓取诊断截图或 CSV。
2. 重点目标词 5～10 个及主要目标岗位；目前“排名低”指哪些词、哪个搜索引擎和设备。
3. 确认国服经营主体以及真实官方账号链接。
4. 如有网站统计，提供按自然搜索落地页的访问/注册汇总，不要发用户级个人资料。

## 观察与验收

- 第 0 天保存索引、展现、点击、自然搜索注册、抓取失败和页面性能基线。
- 技术修改后立即验收线上 HTTP 和交互；再按平台实际权限提交更新页面/站点地图。
- 每周比较品牌/非品牌、页组、设备，不混用总流量；连续观察 4 周，低展现站点需要更长窗口。
- 有收录没展现→检查需求和内容匹配；有展现没点击→检查标题摘要；有点击没注册→查加载、页面信息和流程。不要直接购买外链或频繁改域名。
- 不承诺一周上首页、不承诺固定涨幅；不把收录量增加等同商业转化增长。
