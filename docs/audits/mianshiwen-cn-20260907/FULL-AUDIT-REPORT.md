# 国服 SEO / GEO 审计

审计基线：2026-09-07 发布版本 `cn-home-downloads-20260907.1`，https://mianshiwen.cn/。范围为全站公开页面：sitemap 30 个 URL，以及协议、隐私、登录、不存在路径和域名变体，共 36 次单线程页面检查；不登录用户账户、不读取用户内容、不改生产。

## A. 结论

**网站有可用的 SEO 基础，并非没有收录页面或所有 URL 都返回首页。当前应优先修复访问体验和公开信息缺口，再用百度平台数据确定内容投入方向。**

总体评级：基础具备、需要改善。数值分数：数据不足，不提供伪精确分数。百度实际收录、排名、点击、外链、真实用户 CWV 和 AI 引用未知，不能确认“被降权”，也不能断言某一个问题导致排名低。

最高优先级：

1. 首页依赖状态接口、旧资源发布兼容性（已在本会话前序只读排查复现）。这是用户可用性 P0，不等于已证实搜索降权。
2. `/terms`、`/privacy` 无 JS 请求仍是首页正文，并被 noindex；`/pricing` 虽独立但没有实际套餐金额。
3. 关于页运营主体仍留有待核验说明；域名、内容更新信息有维护缺口。

已有优势：30 个公开页面都有独立标题/描述/H1/正文；静态教程、问题专题和内链已经存在；robots、llms 文件、JSON-LD、HTTPS 和真实 404 已建立。不要重复造一套，也不要删除已有有效页面。

## C. 各项检查

### 抓取、索引和路由

- 30 个 sitemap URL 都有独立可读取内容，包括 `/pricing`、`/download`、`/about`、`/contact`、`/security`，以及 RAG/大模型/Java/前端/算法专题。此前“可能都返回首页”的假设对这些页面不成立。
- `/terms`、`/privacy` 与 `/login` 是额外测试 URL，不在 sitemap；前两项应区别于登录页处理。登录页 noindex 属于正常防重复措施，不能为了收录把工作台开放。
- Baiduspider User-Agent 模拟请求与普通请求的首页 HTML 字节一致；这是本地网络测试，**不是百度官方抓取成功或站点验证通过的证据**。
- 百度验证 meta 标签仍在首页，但后台所有权、抓取异常和提交额度需要平台确认。
- 自建抓取图在本次页面集合内，每个 sitemap 页面都有至少一个入链。不是全互联网孤岛分析；部分专题仅 2～4 个入链，可在相关教程中增加语义明确的链接。

### 内容和关键词

现有内容比“从零搭建”完整。RAG 等页已包含定义、流程、取舍、常见问题、审核团队、日期和论文来源；不应笼统标为全站无作者或无来源。腾讯/Mac 等产品操作指南仍偏概括，值得加入产品实测和截图。

中文页面不套英文单词数下限；字数不足不是自动排名处罚。现有普通功能页约 600～900 个文本字符、深度专题约 2000～2600 个字符仅作结构参考。优先看是否真正解决搜索者的问题。

产品首页与功能总览应明确不同意图：首页回答“面试稳是什么/适合谁/怎么开始”，功能页回答具体使用过程。品牌名和标题不用每次改版都重写；保留稳定 URL。

### 结构化数据与图片

首页含 Organization、WebSite、SoftwareApplication，公开专题含 WebPage/Article 与 BreadcrumbList；本次保存的 JSON-LD 可解析，未发现必须从零补 schema 的情况。解析通过不等于富结果资格通过。

不新增虚构 AggregateRating、Review、客户 Logo 或销量。商业站不把 FAQ 富结果当目标；FAQ 正文本身仍有价值。视频可在实际时长、缩略图、上传日期核实后补 VideoObject，不填推测日期。

抽查教程主要只有装饰 Logo，空 alt 和明确宽高是合理的，不是全站图片缺 alt 故障。两段首页视频与封面已存在，之前实验室记录显示会参与首屏资源加载；建议视口附近再加载非首屏媒体，保留用户控制及音轨。

### 性能与安全

本轮 PageSpeed API 限流，**没有新的 LCP/INP/CLS 字段值或 Google 性能分数**。前序浏览器耗时只能证明实验室可复现等待，不能当百度 P95、真实用户分位数或官方排名信号测量。服务器直测正常也不能否定用户端慢。

HTTPS、HSTS、CSP、X-Frame-Options、nosniff、Referrer-Policy 存在。脚本建议 `microphone=()` 不适用于本产品，会破坏收音，不采纳；不为刷安全评分调整业务权限。

## D. GEO 与可信内容策略

先做好可读取 HTML、清晰问题答案、真实来源和品牌身份，再评估引用。Google 官方明确说明，AI 搜索功能没有额外特殊优化要求，也不要求新的 AI 文本文件或专用 schema；满足条件仍不保证索引或展示。[官方说明](https://developers.google.com/search/docs/appearance/ai-features)

这只说明 Google，不能直接推断百度、豆包、元宝、DeepSeek、Kimi 等平台的内部排序。对于国服，建立一组固定问法，记录平台、日期、是否联网、回答来源链接与是否准确提及产品；与百度搜索分开统计。GPTBot 是训练相关爬虫而非等同搜索曝光开关，不把“允许训练”作为 GEO 必须条件。

## E. 工具限制与误报排除

- SEO 技能参考文件距审计日已超过 90 天，涉及时效性规则只采用已核对的官方来源；未使用技能内未经验证的相关性倍数、流量提升百分比和所谓最佳引用字数。
- requests 默认 Latin-1 解码导致最初脚本中文乱码；原站 UTF-8 正常。已离线修正 HTML/解析，`pages.json` 为复核后的证据。初始提取器移除 header 后漏 H1 的误报也已修正，不据此报网站缺 H1。
- 链接检查 16 个目标中 14 正常，两个政府备案外链出现 521/连接失败。这是外部端点/当前网络下的不可达，不能直接认定备案错误或建议删除备案。
- 外部 web 读取器返回了旧首页文案，而本次直抓/模拟 UA 返回新文案。更像缓存时效差异，未经验证不认定 cloaking/CDN 故障。
- 无百度资源平台、统计账户、真实用户 CWV、竞品采样及 AI 引用基准，故不报告真实排名、收录数量或处罚。
- 未跑无边界全站/外链爬虫，不压测、不下载完整安装包、不改生产。
