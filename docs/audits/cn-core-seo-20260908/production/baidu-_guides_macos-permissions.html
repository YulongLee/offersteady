MACOS PERMISSIONS

macOS 已授权但不能收音，按权限类型重新检查

macOS 会分别管理麦克风、屏幕录制和部分系统音频能力。看到某一项“已允许”不代表其他能力也已生效，授权后通常还需要完全退出并重新打开电脑伴随程序。

macOS 权限已经打开，为什么助手仍然不能用？

最常见原因是只打开了其中一种权限、授权对应了旧版本应用，或者授权后没有完全重启助手。先在“系统设置 → 隐私与安全性”中分别确认麦克风和屏幕录制，再退出托盘中的伴随程序并重新打开，最后用页面音量条验证真实输入。

应该按什么顺序检查？

  1. 确认运行的是产品下载中心当前正式版本，而不是旧安装包或重复副本。
  2. 打开“系统设置 → 隐私与安全性 → 麦克风”，允许面试稳伴随程序。
  3. 需要截图时，打开“屏幕与系统音频录制”相关权限。
  4. 从菜单栏或托盘完全退出助手，而不是只关闭窗口。
  5. 重新打开助手，分别观察“我的声音”和“面试官声音”音量状态。

什么时候才需要重置旧授权？

只有应用已在权限列表中、反复切换仍无效，或重新安装后系统继续引用旧签名记录时，才考虑使用系统授权重置。重置会让对应应用下次使用能力时重新弹出授权请求，不会替你自动点击允许。

不要盲目清空全部权限：应只重置面试稳对应的麦克风、屏幕和音频授权。企业设备受管理策略限制时，需要联系设备管理员。

信息来源与适用范围

本指南依据面试稳当前电脑伴随程序的权限用途、产品使用手册与 Apple“隐私与安全性”设置路径整理。macOS 菜单名称会随系统版本调整，应以电脑当前显示和 Apple 官方支持说明为准。
