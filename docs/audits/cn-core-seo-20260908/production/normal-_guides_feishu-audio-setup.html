飞书中的麦克风设备决定对方能否听见你，飞书的扬声器输出决定你和伴随程序能否听见面试官。两路声音需要分开验证，不要只看到飞书会议正常就认为网页转写一定正常。

飞书面试官声音识别断断续续怎么办？

先确认飞书扬声器确实播放到电脑当前输出设备，再检查助手的“面试官声音”音量条。如果飞书能听见但助手音量始终为零，问题通常在系统音频权限或输出通道；如果音量正常但转写仍断续，再检查网络、对方音质和静音切分。

面试前 3 分钟检查

  1. 在飞书音频设置中选择实际使用的麦克风和扬声器，不要保留已经断开的蓝牙设备。
  2. 让对方或测试音频说一句完整的话，确认电脑扬声器输出不是零。
  3. 打开面试稳助手，确认“我的声音”和“面试官声音”分别出现音量变化。
  4. 网页进入准备页并连接助手后，再进入正式面试。
  5. 蓝牙耳机不稳定时，优先尝试有线耳机或电脑内置输入输出进行对照。

为什么飞书正常，网页仍可能慢？

会议通话、系统采集、网络上传、语音识别和网页展示是连续但独立的环节。飞书通话正常只能证明会议连接可用，不能证明系统授权、伴随程序输入和转写服务全部正常。排查时应以两路音量条和最新转写状态为依据。
