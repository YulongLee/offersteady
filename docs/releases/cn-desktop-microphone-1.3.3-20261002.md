# 国服 Mac 助手 1.3.3：麦克风授权修复

## 基线与范围

- 完整工作区源码先保存并推送为 `78700e6`，标签 `release-20261002.1`。
- 本次发布独立开发分支 `codex/fix-macos-microphone-133`，以正式助手 1.3.2 源码 `fa9db78` 为基础，未带入工作区尚未发布的模拟面试专用采集协议。
- 仅发布国服 macOS arm64 / x64。Windows 与国际服下载版本保持 1.3.2。
- 不修改后端业务代码、模型、面试模式、音频路由、积分计费、机器码身份或数据保存规则，不主动重置系统隐私授权。

## 修复内容

1. Mac 主程序及辅助程序签名补充 `com.apple.security.device.audio-input`，发布校验读取真实签名并验证值为 true。
2. 移除将等待 2.5 秒视为拒绝的处理。区分等待、允许、拒绝、系统限制和检查失败；并发授权请求只弹出一个系统请求。
3. 麦克风下面增加权限状态、检查权限、系统设置入口；未授权或检查失败时提供申请授权按钮。权限请求不依赖后端注册成功。
4. 返回窗口后重新读取系统授权，过期异步检查/请求失败不得覆盖新的授权结果。
5. 空闲麦克风检测等待 OS 允许后再开始，避免授权等待耗尽音频设备打开超时。系统声音通道及正式面试采集协议保持原有行为。
6. 共享文案生成器补充新提示的英文映射以保持标准测试通过；这不代表发布国际服安装包。

## 用户验收

1. 在没有正在进行的面试时完全退出旧助手，下载安装与 Mac 架构相符的 1.3.3，拖入“应用程序”覆盖旧版，再从“应用程序”打开。
2. 未决定过权限时应出现麦克风请求；等待超过 2.5 秒不应被判为拒绝。已授权机器可能不会再次弹窗，应显示已允许。
3. 若显示拒绝，打开系统设置允许该应用，返回检查；必要时完全退出并重新打开助手。无需删除已有机器码。
4. 验证麦克风音量、电脑输出、机器码绑定、普通面试、手机面试和截图仍符合原来的产品流程。
5. 特别请反馈用户在 Intel Mac（macOS 14.2+）验收首次授权与实际收音；若仍异常，收集系统版本、助手版本和权限状态，不要求其提供面试音频。
