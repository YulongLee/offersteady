# 国服笔试多屏回答本地版本

封版说明：本文保留开发及发布时的历史状态；当前已部署源码与最终封版以 [cn-20261019.2](../../releases/cn-20261019.2/README.md) 为准。
范围：用户要求在笔试顶部增加“多屏回答”开关，开启后分别截屏、统一回答。开发分支为 `codex/cn-written-multi-screen`，起点为已确认封版 `release-cn-20261019.1`（`4cdd557b6d15189de6055b3d180a9b2297d7dd7d`）。本轮不部署、不推送Git、不更改封版标签。

变更契约和验收场景见[功能规范](../../openspec/changes/add-written-multi-screen-answer/specs/written-multi-screen-answer/spec.md)、[设计](../../openspec/changes/add-written-multi-screen-answer/design.md)和[任务清单](../../openspec/changes/add-written-multi-screen-answer/tasks.md)。

## 使用方式

笔试顶部开关默认关闭，原“截屏回答”保持。开启后可连续截取当前所选共享屏幕的画面，最多4张，底部显示有序待回答列表，可移除。点击“回答”将这些图片作为一次任务提交，流式显示一个回答；采集阶段不调用AI、不计费，提交沿用现有一次截图回答权益/积分规则。

没有待提交图片、采集或回答处理中时，相应按钮禁用。切关、移除、离开、结束或页面被替代会清理待提交项；截图本身失败保留先前已采集项。批答失败、取消或图片过期时提示重新截屏，不自动重复提交已消费图片。

页面内原截图快捷键跟随开关。桌面助手的系统全局快捷键本轮仍沿用原单图回答；要累积多图请使用页面“截屏”按钮。既有Windows/macOS助手上传契约可复用，本轮没有打包或发布助手。

## 本地预览与验证边界

交互入口：[笔试多屏回答预览](http://127.0.0.1:5180/test-previews/written-multi-screen.html)。它复用实际 `LivePage` 和操作栏，使用明确标记的合成画面与回答，阻断外部fetch，不进行真实屏幕采集、模型调用、线上会话操作或实际扣费。

预览还支持 `?scenario=capture-error` 和 `?scenario=answer-error` 检查错误提示。启动方式（在本功能工作区执行）：

```bash
npm run dev -w @offersteady/web -- --host 127.0.0.1 --port 5180 --strictPort
```

真实桌面+模型的人工联调尚未执行，交互预览及合成API/视觉网关测试不代表真实模型多图回答质量已验收。国服线上、国际服、模拟/普通面试、简历改写/PDF及助手分发未更改。

## 实现与发布前提

capture-only兼容字段默认关闭，新批答入口通过来源请求ID校验用户/会话、图序、可用性、消费占用和去重；受理、取消和完成用同会话锁串行，Redis使用共享锁，生成过程不持有该锁。图片沿用短期内存暂存及原TTL，不保存到浏览器持久存储；未上传的遗留捕获请求过期后释放名额。取消的父请求、任务及晚到图片/事件不能复活。

截图字节仍在单Backend进程内存，沿用封版的单进程启动拓扑。Redis元数据和分布锁不能令字节跨进程可见；未来若改成多worker/多实例，应先解决图像跨进程可读性，不得直接扩容后声称支持。

封版Web含历史静态增量，因此本轮本地构建成功不代表可以覆盖整套线上Web。未来发布仍需按实际目标镜像和静态包核对增量、功能路由及保护门禁，另获部署授权。

## 实际验证

- Web全部63个测试文件、598项测试通过；其中新增14项页面交互及12项adapter回归。
- Web类型检查及生产模式本地构建通过。构建依照原流程匿名读取公开商品目录，仅生成本地文件。
- 浏览器验证默认单图、开启后无图禁答、两次采集后一次回答、窄屏操作与无横向溢出；真实模型/桌面联调未做。
- 新增32项后端回归全部通过，包含合成HTTP完整链路、真实本地计费服务两图只结算一次、图序与取消保护。扩展回归为228项通过、1项语音预热耗时断言失败、8项已复现的封版旧用例排除；耗时用例与32项新测试隔离复跑33项均通过，合计229个不同用例曾通过，不称为同一次扩展全绿。
- `openspec validate add-written-multi-screen-answer --strict` 通过；独立只读评审提出的取消结算竞态、晚到消息复活和遗留请求占位三项已修复并补回归。

Web完整测试有Node既有localStorage运行参数警告，不影响测试结果。生产构建初次因受限环境无法解析公开站点失败；允许匿名公开读取后，同一构建命令通过，没有修改构建规则或绕过商品校验。

后端8项既有失败已从原封版标签导出源码逐项复现，本轮没有顺手修改语音、登录或运行时指标逻辑。测试命令、具体节点与基线源码hash记录在本功能工作区 `artifacts/written-multi-screen/backend-validation.json`。主仓库持久证据目录为 `artifacts/cn-written-multi-screen-20261019/`，保存后端明细、Web/浏览器验收、截图及以封版为起点的源文件增量归档。
