# 国际服网站加载优化 — 本地验收 2026-09-29

## 状态与基线

本地开发及自动验收完成，**未部署线上**。OpenSpec：[optimize-global-web-entry-loading](../../openspec/changes/optimize-global-web-entry-loading/proposal.md)。

以已发布的 `20260929-global-practice-1` 为基线，对照 `artifacts/global-practice-20260929/candidate/` 的国际服 Web 源码与构建产物。开始前源码仅生成的文案/下载清单存在差异；本轮生成后的三个 Global 1.3.2 下载目标与已发布候选一致，未发布或修改助手。

工作区存在其他历史改动，本轮不将它们作为新优化发布。没有修改国服、后端、数据库、模型、支付规则、CDN、DNS 或生产配置。

## 优化内容

1. 首页与登录入口不再等待业务状态接口，也不预加载面试工作区代码；进入受保护页面才加载工作区并验证真实会话。
2. 登录表单不被后台恢复会话阻塞；恢复请求在新登录、输入操作、离开页面时取消或忽略过期结果，避免旧响应覆盖新账号凭据。
3. 宣传视频封面接近可视区域时加载，视频点击播放后才下载；首份静态 HTML 同样移除提前下载的媒体属性，保留说明、尺寸和可访问的打开链接。
4. 保留首页设计、十种语言、会员与下载内容、内部导航及原面试流程。分包加载失败提供重新加载入口。

现有 gzip 与带哈希资源缓存已启用，本轮未把它们当作新增优化。CSS 继续共用，避免额外视觉回归。
