## 探针边界

`probe_model_1017_smoke.py` 与 `probe_model_1017_adapters.py` 只用合成文字/图片，先冻结实际容器ID及固定镜像，然后通过独立Python进程实例化Settings副本。禁止导入app.deps或应用生命周期、启动真实worker、创建会话/资料任务/账务。输出只含固定操作、模型、布尔断言、耗时与固定错误类；不输出原始供应商响应、私有URL、密钥或真实用户日志。

Global摘要补丁的真实验证只在该探针进程内通过精确源码SHA校验和单处替换执行候选模块；不写正在运行的文件，不重启进程。结果同时核对原Settings、实际容器配置和文件未变化。

实际扩展项包括快答/详答流式、JPEG单图与四图顺序、两服启用的简历优化、有/无JD、CN模拟出题/部分报告、CN Responses搜索，以及各worker独立摘要。未启用的Global模拟/搜索不通过测试动作开启。简单合成题只证明接入及协议，不代表已验证所有算法题、真实简历或所有语言；没有执行模型生成代码来宣称代码语义正确。
