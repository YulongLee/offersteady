# OfferSteady release-1.0 发布说明

发布日期：2026-08-22

## 发布定位

`release-1.0` 是面试稳当前商业化产品代码的首个正式封板版本。该标签固定 Web、Backend、Admin、Desktop、协议、部署配置和运维脚本在同一可追溯提交上，作为后续问题修复和版本迭代的稳定基线。

桌面伴随程序采用独立制品版本，目前正式下载制品版本为 `0.1.16`。产品仓库发布版本与桌面制品版本分别管理，避免未重新签名和重新打包时修改客户端版本号。

## 本版能力

- 手机号验证码登录、账号状态与跨设备数据读取。
- 面试创建、资料选择、设备连接、实时双路收音和说话人区分。
- 用户主动触发的快答、手动问题和截图回答。
- 简历、职位 JD、知识资料上传、索引、启停、重命名、下载与删除。
- 面试复盘、面试官问题与用户回答保留、Word 文档导出。
- 积分、时间会员、兑换码、邀请奖励和积分明细。
- 微信支付、支付宝支付及后台渠道配置、订单和收入管理。
- macOS Apple Silicon、macOS Intel 和 Windows 桌面伴随程序分发。
- 管理后台运行监控、收入统计、容量指标和服务状态。
- 公开内容、使用手册、协议、隐私政策以及 SEO/GEO 页面。

## 性能与稳定性基线

- 实时会话事件使用统一事件通道，减少重复状态刷新。
- Redis 事件读取使用游标索引和有界读取，降低长会话尾延迟。
- 截图回答支持图片数据直传视觉模型，不依赖 OSS 持久化截图。
- 回答 SSE、转写事件和历史状态采用单调状态合并，减少页面闪烁和状态回退。
- 生产构建包含环境校验和公开构建清单，错误环境产物不能通过部署检查。
- PostgreSQL 每日自动备份，备份生成后执行格式和校验和验证。

## 封板验证

封板前执行以下检查：

- Backend 全量测试。
- Web、Admin、API、Desktop、Config、Protocol 的类型检查、测试和生产构建。
- 活跃变更的 OpenSpec 严格校验。
- Docker 线上服务健康检查。
- 首页、Backend 健康接口、计费状态、Web 聚合状态和生产构建清单检查。
- PostgreSQL 首份定时备份完整性检查。

## 发布约定

- Git 标签：`release-1.0`
- 稳定分支：`main`
- 后续功能开发不得移动或覆盖该标签。
- 紧急修复应从该标签或对应提交建立修复分支，并以新标签发布。
