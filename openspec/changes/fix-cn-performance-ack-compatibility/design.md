## Context

2026-09-16 国服运行镜像中的路由已传入 route_received_at_ms、executor_admitted_at_ms、answer_generator_started_at_ms，实时服务缺少这三个参数。恢复已存在于正常旧版本中的签名和白名单诊断映射即可；不改变调用方和权限边界。

## Goals / Non-Goals

**Goals:** 恢复现有和旧客户端性能上报，验证实际生产代码，保留可回退镜像。

**Non-Goals:** 不重构实时服务，不调整告警阈值，不掩盖 5xx，不改模型/提示词、计费、数据库、页面或国际服。

## Decisions

- 以当前运行容器提取的源码与镜像 ID 为修复基线；不能以 Git HEAD 替代实际部署内容。
- 服务增加三个默认 None 的显式可选参数，并加入既有白名单诊断字段。拒绝 kwargs 吞掉未知字段或删除路由时间戳的方案，以保留问题定位能力。
- 合成请求通过真实 FastAPI 路由和实际服务方法，依赖替身仅用于身份、会话所有权和诊断存储，避免读取真实用户或调用外部模型。
- 候选镜像由原运行镜像衍生，只覆盖一个已比对哈希的服务文件；不重装依赖或打包脏工作区。

## Risks / Trade-offs

- [Risk] 测试误导入主工作区模块 → 固定 PYTHONPATH 和工作目录，输出并断言被测源码路径。
- [Risk] 上线中断实时请求 → 临近切换复核 live 面试和音频活动；不满足则停止部署。
- [Risk] 丢失回滚基线 → 保留旧镜像标签、修复前源文件独立副本及部署配置。

## Migration Plan

先复现接口 500，再执行修复后新旧字段、权限和内容白名单测试；通过后构建单文件候选镜像，在不连接生产依赖的隔离容器内运行同一合成接口测试。空闲时仅替换国服 Backend，检查健康和最近日志；不创建生产测试账号或面试。

## Open Questions

无；仅恢复已确认的兼容行为。未遇真实用户调用时，不能将健康检查描述为完整用户链路验证。
