## Why

The public site now has a correct crawlability baseline, but it still exposes only two indexable URLs, has variable homepage LCP, and does not publish an explicit AI-discovery source of truth. A focused SEO and GEO growth layer can improve discoverability and citation readiness without changing the authenticated product or any interview, payment, material, or desktop workflow.

## What Changes

- Publish a small, curated set of truthful Chinese public topic pages covering existing high-intent product capabilities and common setup problems.
- Add crawlable topic navigation and include only successful, self-canonical public pages in the sitemap with maintained modification dates.
- Publish `llms.txt` and a compact machine-readable public fact source that points AI systems to canonical product, guide, legal, and topic pages.
- Improve Organization, WebSite, SoftwareApplication, WebPage, and BreadcrumbList JSON-LD using only verified facts; do not add reviews, ratings, customers, legal names, or performance claims without evidence.
- Optimize public-page image delivery, dimensions, loading behavior, route payloads, and immutable asset caching to reduce mobile LCP variability.
- Extend release checks across every public SEO/GEO artifact and retain `noindex`/`no-store` for login, invitation, authenticated, legal, and error routes.
- Preserve the existing visible landing page, calls to action, authentication, interviews, realtime audio, screenshots, materials, billing, payments, desktop companion, and API behavior.

## Capabilities

### New Capabilities

- `public-search-topic-cluster`: Curated public topic pages, truthful content boundaries, crawlable internal linking, sitemap membership, and route-specific metadata.
- `public-geo-discovery`: AI discovery files, canonical public facts, entity consistency, and machine-readable citation entry points.
- `public-search-performance`: Public asset sizing, image delivery, caching, route payload constraints, and performance regression checks.
- `public-search-release-quality`: Release validation for every sitemap-listed topic page and GEO discovery artifact.

### Modified Capabilities

None.

## Impact

- Web: additional static public entries, shared public-page styling/content data, internal links, images, sitemap, robots, `llms.txt`, and SEO/GEO verification scripts.
- Ingress: explicit allowlisted public topic routes, cache headers, and content-security validation.
- Documentation: durable SEO workspace, keyword/page map, execution log, audit report, action plan, and monitoring baseline.
- No backend API, database, authentication, billing, payment, interview, realtime audio, screenshot, material, or desktop protocol changes.
