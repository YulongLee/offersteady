## Context

用户于 2026-10-09 授权替换国服模拟面试语音。独立提供商测试已证明现有服务端密钥可调用新模型（PCM 24 kHz，龙安欢），但尚不能代表产品集成已通过。现有运行镜像为共享文本模型更新后的实际基线；本地 TTS 文件有国际服分支，国服线上文件没有，不可直接全目录覆盖。

## Goals / Non-Goals

Goals：朗读在旧模型下线前迁移，保持提问文本、浏览器音频格式、麦克风轮次隔离和收费不变；流式输出且取消释放资源。

Non-Goals：国际服、助手、页面设计、会员规则、题目生成、ASR、数据库及旧异常记录清理。

## Decisions

1. 在现有适配器中按精确模型名选择协议。新模型使用 `wss://dashscope.aliyuncs.com/api-ws/v1/inference`；旧模型继续走原 realtime 协议。只改名称而沿用旧协议不可行；引入全新 SDK 没有必要。
2. 发送同一 UUID 的 run-task，等待 task-started，再发送已有题目及 finish-task。读取二进制 PCM，校验 JSON 结构、任务 ID、生命周期和有界长度；仅允许一字节跨帧 PCM 余数，结束时不允许残样本。不读取或记录服务商原始报错内容。
3. 两种协议共用原并发信号量、45 秒超时、800 字文本及 90 秒音频上限。新内部生成器通过 aclosing 包裹，消费者取消或重播也会关闭它和 WebSocket，不缓存整段音频。
4. 指令继续读原 `ai/prompts/mock-interview/tts.txt`。新模型不生成题目，不更改普通快答、出题、报告或回声排除逻辑。现有文本继续/重试路径处理 TTS 失败。
5. Settings 默认保留旧协议以避免隐式改变国际服；国服环境显式指定三项模型/音色/端点。最小发布镜像只覆盖当前线上 TTS 文件的共同补丁，校验本地与线上差异仅是已知国际服分支。其余文件继承实际镜像。

## Risks / Trade-offs

- 音色及成本变化 → 明示龙安欢女声；产品积分不变，听感验收待用户测试。
- 任务/PCM 协议差异 → 增加失败、取消、重播及真实候选镜像探针，不以权限测试替代集成测试。
- 上线会短暂重建后端 → 两次检查普通/模拟面试、页面、音频、回答及资料任务均空闲，禁止结束他人会话。
- 旧模型明日下线 → 原镜像/环境可短期回滚，但下线后必须修复新适配，不能把旧模型作为长期回退；文本继续仍可用。
- 用户真实麦克风/浏览器听感无法用服务端探针代替 → 明确标记待用户验收，不虚报通过。

## Migration Plan

严格规格校验；本地回归与合成评测；核对运行镜像及环境；远端保密备份并创建候选镜像；候选镜像实际适配器朗读及取消探针；空闲门禁；只重建后端。检查模型/配置/文件哈希、健康及其它容器未变；失败自动还原环境与原后端镜像，无数据库恢复或镜像清理。记录实际结果及剩余验收。
