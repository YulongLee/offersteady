## Goals / Non-Goals

**Goals:** 降低过密后台查询；首段先行、最终问题及时执行、任务和内存有界；按当前身份/资料正确命中；保持字幕与显式点击非等待、详细检索/计费行为；提供合成本地可复核证据。

**Non-Goals:** 不调整 Web/助手、字幕或 question-stable 事件展示频率、VAD/ASR、Prompt/模型、计费、模拟面试、轮询、连接池、生产指标口径和环境变量；不发布 Global 或其它组件。不承诺本地调用降幅等于线上整体 P95 降幅，不调用真实供应商或使用真实用户材料做发布测试。

## Decisions

1. 使用可替换的小型内存调度器，固定两个 worker，通过 Condition 选择可执行任务，不为每个字幕创建 Timer 或堆积隐藏 Future。按 owner/session/question 保留最新待办，首段立即；后续默认 quiet 350ms、最长等待 1500ms、待办 TTL 10s、最多 256 个键。普通更新不能绕过该键的运行任务；final 优先就绪。有空闲 worker 时，final 可越过该键尚未结束的旧 partial，单键最多两项运行、全局始终最多两项，防止慢旧查询阻挡最终问题。相比只做尾部防抖，这保留早期准备；相比完全单飞，有限 final 例外保护最终资料准备速度。
2. 预取 worker 与原 cold 队列分开，现有字幕、usage 和持久化提交保持。短内存锁保护 stable state 的 revision/final 单调性，迟到 partial 不倒写 final；相同稳定文字的更新 final 也提示调度器。结束/清理/shutdown 撤销待办和 token，运行中的同步 IO 自然结束。清理与纯内存入队共用短锁边界，外部事件 IO 始终在锁外；旧 observer 使用状态对象身份及有界 session generation 拒绝跨清理/重置的迟到调用。调度器不持锁调用 Chat/外部函数。
3. 调度时生成 `is_current` token 回调，Chat 在读取前、检索前后及写缓存前检查。缓存保留回调，写入后复检并仅删除同一 generation 的失效结果；命中时锁外再次检查纯内存令牌，避免提交边界撤销竞态。回调始终在 Chat 锁外执行，调度器也不持锁调用 Chat。仅取消尚未执行的过期预取，不强杀运行中的 SQL/HTTP，不取消其它冷任务；同时保留 Chat 自己的同 revision 唯一 generation 防护，避免同问题资料变更的慢旧结果覆盖新结果。
4. 缓存指纹覆盖请求 owner/session、binding owner/session/revision/选择 ID，以及每份 bound document 的 ID/kind/version/status/index/active/collection 等检索可见身份，稳定排序并只存摘要。预取开始及完成时检查当前资料；点击复用已有授权 session 快照，不能增加点击读库。该 retrieval 路径没有显式知识资料 ID/version 时原服务直接空返回，无全库隐式检索，故无需新增 corpus 查询。
5. 问题仅规范空白后全文匹配，放弃有歧义的双向子串复用。明确记录这会使旧 partial 与更长 final 不同文本时 miss；以首段先行、final 优先和命中率/引用用例验证保护准备效果。未命中沿用原 quick fallback，详细检索照常；不扩展缓存到其它用户/会话/问题。缓存与 generation 状态均有界、最多 128 个问题键、60 秒有效期，失败/过期/资料变化不能缓存成有效结果。
6. 本地先运行新缺陷回归、相关普通/模拟/计费/字幕/资源/Global 兼容用例；再在冻结实际 CN 源候选迁移最小方法及新模块，验证所有未批准节点、Prompt 与功能路由保留。合成对照必须报告实际 admitted 检索次数、并发/队列边界、leading/final、点击非等待、引用版本和缓存命中；使用固定合成 provider，不能声称已完成真实模型主观质量或线上负载验收。

## Risks / Trade-offs

- 限频过强降低 quick 的有效资料准备 → 首段立即、有限等待、final 优先；比较有准备时间与即时点击两个窗口，后者沿用原 fallback 并验 detail 正确。
- 只看 selection revision 漏掉资料重处理 → 同时核对文档版本、状态、活动和集合；提交及命中验证。
- final 被慢旧请求阻挡 → 空闲第二 worker 可并行 final，但总并发不增加；两 worker 都忙时仅保留最新待办。
- 取消错误任务或锁反转 → 独立预取队列、按键 token、安全边界退出、外部调用不持调度锁。
- 新缓存完整校验增加单次 admitted 预取读取 → 同负载比较总检索/总会话读取；点击阶段仍保持一次授权 session 快照。
