## Context

前两轮检查已经确定首页及四个承接页的基本索引信号正常，搜索量和百度实时排名未知。继续基于 `artifacts/cn-homepage-layout.82qdGV/candidate` 本地国服候选，不向根目录旧版应用复制源码。根 README 部分阶段描述早于生产，应以已验证的候选功能与近期发布记录为依据。

## Goals / Non-Goals

Goals：让求职者直接理解实时建议的来源、技术场景中的使用方法、费用边界和下载后的准备步骤；机器可读说明与公开页面一致；四页无新 JS、段落可定位，保持静态页面预算。

Non-Goals：不承诺排名、审核或转化结果；不改首页布局、模型、数据库、支付或下载实现；不新增页面和竞品比较；不发布。

## Decisions

1. 复用现有 HTML 和公共样式。比增加框架或 CMS 更适合本轮静态内容变更。首页、新路由和业务 JS 均保持不变。
2. 实时页增加资料选择、识别问题的处理及合成说明示例；技术页补充 Java/前端场景、项目追问与核实建议。不将说明示例包装成运行记录，不增加 AI 主动提问或评分功能承诺。
3. 价格页保留生产目录生成标记和生成代码，只编辑选择依据和购买前问答；不复制数字，不改变 checkout。已核实首页下载区位于首屏但无稳定锚点，下载页首要入口因此直接指向 `/`，标为“到首页下载 Windows / macOS”，不虚构锚点、不改首页代码。保留登录和安装说明，避免把登录当下载前提。
4. 四页使用 scoped body class，增加段落锚点、可见更新时间、轻量侧栏导航；样式仅影响这四页，并保留 reduced-motion 和键盘焦点。其他专题样式不重做。
5. GEO 保留 schemaVersion 与既有字段，更新描述和实际修改日期；不复制永久价格。技术页锚文本明确程序员/技术岗位。JSON-LD 只保留 WebPage/BreadcrumbList 并更新对应描述和日期。
6. 只更新本轮四个页面 sitemap lastmod（本地候选日期），首页排版的 lastmod 待正式发布核对。Nginx 仅替换四项 JSON-LD 哈希，不放宽 CSP 或改重定向。
7. 回归测试检查结构、语义证据、URL 集合、GEO一致性、无新增运行脚本、移动端和内链；运行构建、类型、全部已有测试，逐项对照原10项失败，不能声称全绿。

## Risks / Trade-offs

- 内容增长可能影响扫描阅读 → 简短问答、目录锚点、说明示例，不在首页堆叠。
- 构建静态价格可能过期 → 继续现有生产价格读取与发布前核对，不回退历史价格。
- JSON-LD 改动被 CSP 拦截 → 计算精确哈希并同步候选 Nginx，测试校验。
- 地图 lastmod 仍是候选日期 → 交付明确未部署，发布时核对真实生效日期。
- 排名和 AI 引用未测量 → 记录未知，后续用百度数据与固定查询样本验证，不生成评分。
