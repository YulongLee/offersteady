## Context

用户先批准既有四页的内容优化与本地预览，2026-10-27进一步授权部署国服Web。国服封版提供328份静态字节；仓库通用Web源码重新构建不能自动代表已部署应用。采用基线增量，先核对首页渲染源与实际产物，再选取最小内容更改。

## Goals / Non-Goals

**Goals:** 四页意图清楚、内容具体、权益准确，保持现有视觉和入口，本地提供可审阅页面。

**Non-Goals:** Git提交、比较页/资源中心、业务和模型改动、价格变更、真实用户/供应商调用。

## Decisions

- 静态专题在现有HTML上增加合成问题、资料、建议与核实步骤；复用既有CSS，以页级新增类补充布局，避免改变其它指南。
- 首页保持现有结构和交互，初始HTML与用户可见渲染文本同步。封版资产只允许精确可审计的首页内容增量；不能用全量构建覆盖已部署应用。
- 保留pricing-static.mjs目录生成规则和模板标记；权益作为单独可见说明，不改变商品金额或计费服务。预览目录使用封版已有价格，明确原同步时间；发布前需重新读取公开目录核对。
- canonical保持线上正式URL；不为预览创建搜索提交，也不加入FAQPage标记。结构化数据如有变动须同步CSP脚本hash。
- 更新必要的llms/public-facts产品事实，记录不保证排名效果。日期只表示本地核对，不冒充已发布。

## Risks / Trade-offs

- [基线源码与产物不一致] → 从封版静态包组装候选，记录逐文件差异与应用资产守恒检查；不能把预览误称已上线。
- [首页初始内容和React替换不同] → 对两个渲染表面做一致性检查，在浏览器实际加载后核对。
- [权益被理解为无限免费] → 明确北京时间每日刷新、独立功能额度和超额计费。
- [价格快照陈旧] → 保留原时间并注明订单为准；未来上线前另行核对，不触发购买或账务操作。

## Migration Plan

用户已授权发布。仅对国服Web准备固定镜像增量，先读取实际运行Web镜像、完整静态清单、Nginx和当前公开目录；任何未解释漂移停止切换。原静态资产全部保留，新增经过完整依赖引用图重链接的版本化JS，修改4份入口HTML仅切换资源引用，以维持共享模块唯一性。价格按新鲜公开目录生成，JSON-LD日期与精确CSP hash同步；sitemap仅更新四个目标既有URL的lastmod，不增删URL。

沿用最新只读门禁：普通/笔试/模拟面试、准备页、页面租约、音轨、未完成回答、资料和简历任务、账务操作均须安全。准备前和最终切换前重复检查，不结束真实用户、不清理活动、不放宽门禁。优先资源先安装、页面逐文件原子替换及Nginx平滑reload，避免主动中断连接；用运行镜像为基底构造并验证持久化候选/回滚镜像，按实际环境和Compose记录固化。若采用容器切换，仅Web且门禁通过后执行，原环境、挂载、其它组件必须保持；验收失败自动回到原固定镜像/原静态字节。生产私有配置仅保留服务器。

验收包含完整文件/导入图/CSP、普通与模拟/笔试/简历入口、公开价格和下载，短时脱敏错误统计。没有数据库迁移、账本/会话/模型或AI行为更改，不更新国际服、助手、Admin、Backend或worker。归档与已封标签不改，不执行Git提交推送。
