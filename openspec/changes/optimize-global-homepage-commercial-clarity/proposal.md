## Why

The owner requests a commercial-quality homepage following the merchant-review release. The current first screen is policy-heavy; repeated workflow/features/videos delay pricing and useful actions. There is no conversion analytics baseline, so improvements must be framed as usability hypotheses, not measured uplift.

## What Changes

- Shorten the hero and keep Start free prominent with existing verified downloads and a one-line responsible-use note.
- Replace repetitive feature blocks with four outcome-oriented feature descriptions; present actual pricing earlier and consolidate repeated access disclosures.
- Retain both existing videos in a compact product-tour section, existing anonymous feedback unchanged, and the dated competitor comparison behind an accessible disclosure.
- Add factual FAQ and a clear final Start free action; preserve visible legal operator, support and policy links.
- Keep static homepage copy/metadata aligned with React, with no runtime API additions.

## Capabilities

### New Capabilities
- `global-homepage-commercial-clarity`: concise, truthful and responsive public homepage conversion journey.

### Modified Capabilities
None. Existing merchant disclosures, prices, legal routes and product workflows remain requirements. This owner-approved presentation change replaces the prior long homepage hero and module ordering only.

## Impact

Global homepage presentation, shared public hero strings, static generation, tests and docs. No domestic changes, backend, authentication, billing/entitlements, AI, capture or private data changes. No deployment in this task; no new analytics, guarantees, testimonials, scarcity or unsupported competitive claims.
