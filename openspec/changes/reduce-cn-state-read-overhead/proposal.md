## Why

2026-10-28 国服 11:11:37 的 API P95 为 1,235.15ms，15 次文字回答启动均超过一秒，页面状态读取中位 1.49 秒。实际运行基线已核对：Backend `2f2c8935…` 的 230 个运行文件与 10 月 22 日封版完全一致，Web 为 10 月 27 日 `9261bdb4…`；既有鉴权优化仍在。高频后台工作与聚合状态读取共享资源，当前 Web 状态入口未合并在途请求，资料列表与会话刷新仍独立读取相同资料。

用户明确授权本地优化、自测，晚上另行部署。本轮选择保持新鲜度的请求合并和请求内复用，不把瞬时连接数误当性能目标，不承诺合成测试等于线上 P95 降幅。

## What Changes

- 国服 Web 仅合并同一适配器、同一有效登录身份/凭据代次、同一读取模式下尚未完成的状态请求；不增加成功结果 TTL 缓存。
- 保留登录/退出/令牌变更、业务更新、显式刷新等权威读取边界；取消、失败和迟到响应不得污染后续读取或其它账号。
- 国服 `/web/state` 在单次请求内复用已取得的当前用户资料记录，减少会话绑定刷新时的逐资料查询；缺失引用仍走原权威查询。
- 补充合成并发/取消/身份隔离、资料生命周期/版本、现有功能回归和资源计数对照。
- 在隔离本地环境评估短连接与有界连接复用的成本；本轮不直接接入生产连接池、不调整后台预取/助手协议/模型或收费。

## Capabilities

### New Capabilities

- `cn-inflight-state-read-coalescing`: 国服状态请求在途合并、独立取消和新鲜度屏障。
- `cn-request-scoped-document-reuse`: 单次聚合状态请求内的资料记录复用，保持权限与生命周期语义。
- `local-state-read-performance-verification`: 合成回归、资源计数、连接复用评估与仅本地交付。

### Modified Capabilities

无。既有身份、会话、资料、计费和实时面试的外部业务合同保持。

## Impact

目标为 `apps/web` 的状态适配器/必要刷新边界，以及 Backend 的 Web 聚合、DocumentService、SessionService 最小节点。不得混入国际服、助手、AI Prompt/模型、数据库迁移、收费或页面设计变化。既有 SEO 未提交增量和已发布的模拟面试、简历优化、笔试多屏能力均保留。

仅使用合成账号、资料和状态作测试，不将生产用户正文或凭据写入夹具。无生产部署、重启、配置/用户数据修改、真实模型请求、压测或 Git 提交推送；晚间发布需要按当时实际镜像重新冻结和核对。
