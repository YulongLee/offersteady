## Goals / Non-Goals

**Goals:** 减少同身份并发状态读取与单次聚合内重复资料查询；保留每次新请求的权威新鲜度、逐请求服务端鉴权、全部功能与收费。提供并发/生命周期测试和有样本数、错误数、资源计数的本地对照结果。

**Non-Goals:** 本轮不做跨请求成功数据缓存、放宽鉴权、后台模型/预取或助手轮询策略变更、生产连接池接入、数据库迁移/配置变化、增加 worker、上线、Git 提交推送或真实用户/模型测试。连接复用仅作隔离本地评估，不能把实验实现复制为产品连接池。

## Decisions

### 1. 仅合并尚未完成的同作用域状态请求

合并范围为单个国服适配器/相同 API base、相同登录生命周期、相同用户/凭据与 auth 模式。成功与失败一旦完成就清理，不设置成功 TTL。每个调用方得到独立状态对象，避免共享可变 UI 状态。请求注册与清理使用对象身份，旧请求迟到不得移除新 flight。

认证作用域在登录、退出、清除凭据及跨页认证变化时递增；同账号退出再登录也不可加入旧请求。401 的合法同会话 refresh 仍能成功；refresh 返回前核对发起时凭据/生命周期，防止退出或切换身份后恢复旧账号。作用域只在内存中使用，不把 token 写入日志、诊断或持久缓存。

新增可选 force-refresh/失效能力，精准覆盖会影响聚合状态的写入及现有显式刷新入口。业务写开始与结算后（含可能已在服务端成功的网络失败）形成新鲜度屏障，后续读取不能加入写入前的 flight。独立资料/支付/模拟/简历客户端也必须覆盖，不能仅处理适配器自身方法；高频 ACK、心跳和只读 POST 不触发无意义失效。认证变化后的迟到结果不得回填当前账号。取消/失效不能被当作登录过期清除一个仍有效的新会话。

每位消费者的 AbortSignal 独立生效；单人取消不会终止其它消费者仍需要的网络请求。消费者全部离开时允许取消底层请求并释放记录；失败和取消后下一次正常发起新请求。不改变普通 JSON 错误合同及 SSE、音频、回答/截图传输。

读取期间业务代次改变时，最多自动重读一次当前作用域；再次失效则按取消/可重试结果结束，不无限重试。认证生命周期改变直接拒绝旧结果。401同会话刷新更新当前凭据而保留合法认证生命周期，不能将其误报成换账号。

替代方案是 1.5 秒成功缓存（旧研发方案）；它增加资料与支付状态陈旧风险，且用户要求保持体验，因此本轮不用。替代方案是全局跨账号共享 Promise，也因隔离与测试风险排除。

### 2. 聚合请求复用原始资料记录而非显示投影

DocumentService 为同一次完整 owner 列表读取提供内部快照，包含原始 DocumentRecord 及原有显示响应；原 list_documents 合同与排序/重名消歧保持。原始记录只能在本请求中传递，不进入 HTTP payload、全局对象、缓存或持久化。

SessionService 的可选 seed 仅接纳 owner 和 document ID 一致的原始记录，并复制为本次调用的 lookup；不改变其它入口默认行为。列表未覆盖的绑定 ID 继续权威 `get_by_id`，不能把 include_deleted=False/过滤造成的缺失推断为删除。正常 ready/index 状态、版本、summary、知识库归属、binding revision 和 integration references 维持原算法；mock 使用选定版本的短路保持。下一次 HTTP 请求重新取列表与缺失引用，不复用上一请求快照。

仅国服 Web 聚合入口传递 seed；Global 和其它调用点走原合同。返回响应的重名显示名不能作为绑定原始 display_name，避免复用投影改变数据语义。

请求内快照代表本次列表读取的时点，不保证与之后才提交的资料变更原子同步；下一次请求重新取得当前记录。开始面试、正式回答等权威动作仍沿原路径独立校验资料，不能依赖展示快照绕过删除或权限变化。

替代方案是跨请求资料缓存，因删除/版本变化滞后排除；直接从 UI response 构建 seed 因字段和显示消歧差异排除。大范围仓库/连接生命周期重构超出低风险增量。

### 3. 以资源计数和安全矩阵验收

合成前端并发波次比较实际 fetch 次数、独立取消、后续新鲜读取、失败重试及身份切换；后端用多会话共享资料的合成数据比较 list/get/连接/查询次数，并证明 wire 与绑定语义一致。隔离 PostgreSQL 上评估短连接和有界复用，使用相同 SQL、并发和样本，记录 p50/p95、建连数、错误、事务/异常清理和资源释放。

连接池评估独立于产品依赖与运行时，不修改 .env、生产数据库或现有本地业务库。实验应拒绝非 localhost DSN、使用专属合成数据库/容器，不访问供应商。若实验不可运行，记录具体限制，不虚构结果。

## Risks / Trade-offs

- [mutation/登录边界遗漏导致旧状态回填] → 独立客户端统一精准失效，force-refresh，ABA/迟到响应回归及独立审查。
- [单调用方取消伤及共享请求] → 独立消费者取消与全部离开场景测试。
- [资料投影/缺失被误用] → raw record owner/id 检查、同名资料、deleted/missing fallback、mock 与新请求变化场景。
- [串行新请求没有 fetch 降幅] → 明确仅并发合并；不以 TTL 人为制造命中，不将合成降幅套用线上。
- [短连接少不等于所有延迟解决] → 连接复用仅评估；不以连接总数下降作为成效，保留错误/首字/新鲜度指标。
