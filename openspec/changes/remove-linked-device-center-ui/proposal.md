## Why

当前设备页展示“已关联设备”、在线/离线状态、系统权限和诊断入口，但这些信息不能帮助用户完成下载或安装，反而增加理解成本。设备页应聚焦用户真正需要的助手下载、版本选择、安装和授权说明。

## What Changes

- 从 Web 设备页移除“已关联设备”、在线状态、当前面试状态、权限诊断和刷新状态入口。
- 用户打开设备页时不再请求账号设备列表，避免为不可见功能产生额外请求。
- 保留电脑伴随程序下载、芯片/系统版本选择、安装和授权说明。
- 保留后端设备关联接口、助手心跳、准备页绑定和面试连接能力，不改变桌面助手运行链路。

## Capabilities

### New Capabilities

- `device-download-page`: 设备页只承载伴随助手下载、版本选择与安装授权指引，不展示账号设备状态中心。

### Modified Capabilities

无。

## Impact

- 影响 Web 端设备页组件、相关样式和页面回归测试。
- 不修改 API、数据库、桌面助手或面试连接协议，不需要重新编译桌面助手。
- 本变更取代 `fix-device-center-and-add-referral-rewards` 中“在 Web 设备页展示真实设备状态与诊断”的界面要求，但不撤销其后端设备关联与运行时能力。
