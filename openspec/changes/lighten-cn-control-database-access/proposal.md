- 国服绑定状态解析只取必要的会话归属、状态、模式与音频模式，避免完整资料刷新与附带会话写入；保留绑定、租约、owner、generation和捕获规则。
- 在有限热点PostgreSQL仓库加入国服显式启用、数量与等待均受限的连接复用；默认关闭，保留原事务、权威读取和失败合同，不重放业务写入。
- 以隔离本地真实PostgreSQL验证连接归还、异常/回滚、身份和收费新鲜度、并发与资源释放；记录建连/借用、查询和操作耗时的可得分项与局限。
