## Why

当前后台没有百度自然排名的统一视图，无法快速判断已配置关键词的收录与排名变化。百度 PC 排名服务可以按域名和关键词返回排名、页面标题和页面链接；将结果按天保存并在后台展示，能让运营人员在不登录第三方控制台的情况下查看趋势，同时避免把查询请求放在用户访问链路上。

## What Changes

- 增加服务端百度 PC 排名查询适配器，按配置的域名和关键词调用外部 API。
- 增加每日一次的排名同步任务，使用 Asia/Shanghai 日期幂等写入，记录成功、未找到（排名超过返回范围）和接口错误等状态。
- 增加后台“搜索排名”视图，支持管理员维护关键词列表，并展示每个关键词返回的前 50 条结果、最近同步时间和数据状态。
- 增加受权限保护的后台查询与刷新接口；支持管理员手动刷新，但不在页面加载时自动触发外部调用。
- 增加服务端环境变量和部署文档说明；密钥只允许从服务器环境读取，不进入前端、日志或审计详情。
- 增加适配器、同步幂等、权限和后台展示的测试。

## Capabilities

### New Capabilities

- `baidu-ranking-monitoring`: 管理百度 PC 关键词排名的配置、每日同步、历史结果和后台只读展示。

### Modified Capabilities

- 无

## Impact

- 后端：新增排名数据模型/迁移、百度 API 客户端、同步任务和管理员 API。
- 管理后台：新增“搜索排名”导航项和结果表格，复用现有管理员会话与权限体系。
- 配置/部署：新增百度 API endpoint、AccessKey/Secret（或 AppCode，按实际交付凭据类型）和目标域名/关键词配置；需要为每日任务增加一个 worker/cron 入口。
- 外部依赖：每天最多按关键词数量产生一次查询请求；超时、限流和错误不会阻塞正常用户请求。
