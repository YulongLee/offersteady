## ADDED Requirements

### Requirement: 首屏行动入口清晰
国服首页首屏 MUST 保留“免费使用”主要行动及现有 Windows/macOS 下载组件；导航和页脚中的下载入口 MUST 继续可用，不得新增重复下载组件。

#### Scenario: 访客从首屏开始使用
- **WHEN** 访客打开国服首页并查看首屏
- **THEN** 页面同时展示产品定位、“免费使用”主要 CTA 和 Windows/macOS 下载按钮，下载继续由真实发布 manifest 提供；Mac 架构菜单和键盘操作保持可用

### Requirement: 匿名价格入口可达
首页价格区域 MUST 为未登录访客提供指向公开 `/pricing` 页的入口，不得要求访客先进入内部认证账单路由才能查看价格。

#### Scenario: 访客查看价格
- **WHEN** 未登录访客点击首页价格区域的查看价格行动
- **THEN** 浏览器打开公开 `/pricing` 页面，并可在未登录状态看到套餐信息

### Requirement: 响应式版式稳定
首页 MUST 在桌面和窄屏视口下保持单一主列阅读顺序；首屏双栏内容在窄屏下 MUST 堆叠，CTA 不得溢出或被遮挡。

#### Scenario: 窄屏浏览首页
- **WHEN** 视口宽度低于现有移动断点
- **THEN** 首屏内容按产品定位、主要 CTA、下载入口、演示内容顺序垂直排列，页面无横向滚动

### Requirement: 业务流程不变
版式优化 MUST NOT 改变登录、支付、下载、面试会话和后端 API 的行为。

#### Scenario: 用户使用现有业务入口
- **WHEN** 用户从首页进入登录、价格、下载或面试相关入口
- **THEN** 入口继续使用原有 URL 和业务流程，优化仅改变展示层级与样式

### Requirement: 产品展示可核实
首页 MUST 复用项目真实界面的合成示例截图并标注演示性质，MUST NOT 使用真实用户资料、伪造评价或性能数字；访客 MUST 能切换项目追问与截图问题示例并查看大图。

#### Scenario: 访客查看产品演示
- **WHEN** 访客选择截图问题示例
- **THEN** 预览图、图像描述及大图链接同步切换，操作不创建面试、不启动收音、不调用模型

### Requirement: 商业信息清楚且保持真实
操作教程 MUST 位于套餐之前；套餐金额、有效期 MUST 复用现有目录，积分费率 MUST 复用现有配置，首页 MUST 解释积分和会员区别及知识材料的额外计费边界。

#### Scenario: 访客比较使用方式
- **WHEN** 访客浏览套餐区域
- **THEN** 可看到当前发布套餐的真实金额和有效期、积分按功能消耗与会员有效期权益的区别，以及公开价格、计费手册与订单支持入口

### Requirement: 套餐选择只改变展示
首页 MUST 展示所有有效已发布会员套餐的金额与时长，并允许选择查看对应权益；MUST NOT 因选择触发订单、支付或后端写操作。

#### Scenario: 切换会员时长
- **WHEN** 访客选择另一个有效会员时长
- **THEN** 当前金额、有效期、知识材料额度与该目录项一致，公开价格链接保持可用

#### Scenario: 目录变化
- **WHEN** 当前选中套餐被下架或变为无效
- **THEN** 页面回退到首个有效套餐；无有效套餐时显示无可用套餐信息，不显示历史价格
