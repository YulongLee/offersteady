## Why

用户要求将国服 2.0.0 浮窗测试版封装为正式版本，供之后部署。当前测试包只覆盖各平台不同阶段，不能直接作为统一正式候选。

## What Changes

- 基于现有获验收的 1.3.6 伴随助手和 2.0.0 浮窗功能，准备国服 Apple Silicon、Intel 和 Windows x64 的 2.0.0 本地候选。
- 保留正式助手原有设备身份、功能、音频和权限流程；浮窗沿用已测试的交互。
- Mac 包按正式签名及公证流程验证，Windows 包如实标明签名状态；记录实际未完成的真机验收。
- 明确 Zoom 共享及录制显示浮窗的已知限制，不能对第三方隐藏作无条件保证。
- 本变更仅准备和验证本地候选，不部署、上传、更新下载入口或触发真实业务。

## Capabilities

### New Capabilities

- `cn-companion-2-0-0-packaging`: 国服伴随助手三平台候选封装、身份保持、真实状态和验收证据。

### Modified Capabilities

无。

## Impact

影响桌面助手构建、安装包与本地文档；不改变线上服务、模型、收费或数据。验证默认使用合成数据，不保存真实音频、截图或个人资料。
