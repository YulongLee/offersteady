## Context

公开首页已有英雄区、三步流程、收费方案和价值证明，但缺少一个覆盖主要产品能力的集中概览。用户提供的参考图采用居中标题与两列六卡布局；实现需要保留这种快速扫读结构，同时适配面试稳当前深色设计、现有公共站点宽度和真实功能边界。

本次是纯前端展示变更。卡片图标需要一致的线性视觉语言，因此引入可按组件单独导入、支持 TypeScript 和无障碍属性的开源 React 图标库。

## Goals / Non-Goals

**Goals:**

- 在首页用六张卡片清楚呈现当前核心能力。
- 桌面两列、小屏单列，并保持标题、图标、正文层级易扫读。
- 复用现有公共站点色彩、边框、圆角、字体和响应式断点。
- 文案真实、克制，不出现无法验证的准确率、Offer 保证或隐蔽使用承诺。
- 图标对辅助技术保持装饰性，语义由可见标题提供。

**Non-Goals:**

- 不照搬竞品品牌、文案或亮色主题。
- 不新增页面、交互流程、接口或产品能力。
- 不声明所有视频会议平台或所有语言均已完成验证。
- 不修改首页现有收费、备案、协议和隐私说明。

## Decisions

### 在工作流区之后增加独立能力区

六卡区放在现有“从准备到现场”之后、收费方案之前。用户先理解产品怎么使用，再完整浏览能力，最后进入价格选择，信息顺序更自然。

替代方案是扩充现有三张价值卡，但会混淆“核心能力”和“选择理由”，也无法保持参考图的六项快速浏览结构，因此不采用。

### 沿用参考结构而不是复制视觉主题

桌面使用两列三行、每卡左侧图标右侧文案；小屏切换为单列。颜色和材质使用面试稳现有深色变量，卡片通过轻微边框、悬停和焦点反馈增强层级。

替代方案是完整复制参考图的浅色背景，但会割裂当前首页品牌并增加主题切换范围，因此不采用。

### 使用 Phosphor React 图标

选用 `@phosphor-icons/react` 的统一线性图标，并仅导入六个实际使用的组件。该库提供 TypeScript 声明、可调线宽和 React 组件接口，适合当前卡片尺寸与构建链路。

替代方案包括自制 SVG、字符图标和生成位图；前两者难以保证一致性与可维护性，位图在小尺寸和高分屏下不如矢量图标清晰，因此不采用。

### 文案按已存在能力映射

六项分别映射到实时问题识别与回答建议、截图题处理、知识库、简历/JD 按场选择、会话复盘、桌面伴随与手机同步查看。平台文案只描述已经存在的支持范围，并保留“AI 内容为建议”的产品边界。

### 使用合成场景而不是伪造用户背书

新增故事区沿用参考图的两列六卡和角色信息层级，但不使用姓名、头像、五星评分、具体雇主或录用结果。每张卡片明确标注“合成示例”，使用岗位与面试阶段描述如何组合现有能力。

替代方案是仿照参考图编造具名用户与大厂任职信息，但这会让访客误以为内容来自真实客户评价，也增加广告合规和品牌信任风险，因此不采用。

### 用产品事实替代未经验证的经营数据

参考图顶部的四项数字结构予以保留，但内容改为当前页面和产品能够直接核验的“3 种问题输入、6 项核心能力、2 种使用方式、200 点免费额度”。不展示累计用户、面试场数、题库量、岗位量或效率提升比例，直到存在可信的统计口径与数据源。

替代方案是使用竞品数字或为面试稳估算相近数据，但估算无法在页面上得到验证，可能误导访客，因此不采用。

### FAQ 使用原生 details/summary

六项 FAQ 使用原生 `details` 和 `summary`，第一项默认展开。这样无需新增状态管理即可获得键盘操作和展开语义；统一的 Phosphor 下拉图标提供视觉状态，答案中涉及积分费率时使用当前运行时计费状态。

替代方案是自制手风琴按钮和隐藏面板，但会增加状态、ARIA 关联和回归范围，因此不采用。

## Risks / Trade-offs

- **首页内容变长并与价值卡重复** → 核心能力卡聚焦“能做什么”，现有价值卡继续说明“为什么选择”，文案避免重复句式。
- **新增图标依赖增加包体积** → 使用具名导入并通过生产构建检查 tree-shaking 后的产物变化。
- **平台能力文案过度承诺** → 不列举未经验证的平台和语言，不使用准确率数字或绝对安全措辞。
- **小屏卡片过密** → 在 720px 断点切换单列并缩小外边距，保持每卡正文自然换行。
- **用户把场景示例理解为真实评价** → 区块引言与每张卡片均显示“合成示例”，并避免星级、姓名、头像、雇主和录用结果。
- **固定数字随产品配置变化而失真** → 只使用稳定的能力数量，免费积分和消耗费率从当前计费状态读取。
- **FAQ 与正式说明冲突** → FAQ 保持摘要级信息，并链接用户协议、隐私政策或登录后的详细说明入口。
