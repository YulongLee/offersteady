## Why

国服面试期间的用户请求 P95 会被管理后台查询和重复状态读取拉高，部分只读接口也存在不必要的数据库往返。需要在不改变用户流程或响应内容的前提下，降低读路径开销并让监控口径真实可用。

## What Changes

- 将管理后台请求从用户请求 P95 中独立归类。
- 为面试状态、历史摘要和桌面绑定等只读路径增加必要的查询优化与短时缓存/去重边界。
- 保持现有 API 响应结构和业务时序不变，增加回归测试与性能观测字段。

## Capabilities

### New Capabilities
- `cn-read-path-performance`: 定义国服只读请求的低风险性能优化和监控口径。

### Modified Capabilities
- `admin-monitoring-breakdowns`: 管理后台请求不应计入用户请求 P95。

## Impact

- 影响后端请求分类、只读服务访问和管理监控测试；不改变面试、ASR、AI 回答、截图或计费流程。
- 无新增外部依赖；不改变数据库数据模型。
