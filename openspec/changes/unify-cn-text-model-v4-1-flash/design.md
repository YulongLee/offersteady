## Context

2026-10-08 已读取国服正在运行的 backend 和 material-worker 设置，两者共享模型为 `deepseek-v4-flash`，快答/详细回答的独立覆盖均为 `deepseek-v4.1-flash`。已部署的模拟面试适配器和资料摘要适配器直接读取 `chat_qwen_model`。这些链路不需要新增代码路由即可迁移。

## Goals / Non-Goals

**Goals:** 将国服全部现有 DeepSeek 文本链路统一为 v4.1；验证结构化摘要、最多十题的模拟出题与报告兼容；保护现有普通面试流程和积分规则；记录真实运行配置与验证结果。

**Non-Goals:** 不替换语音、视觉、检索模型，不改国际服、不升级助手、不改提示词/数据库/支付、不部署整个工作区、不宣称自动测试等价真人验收。

## Decisions

- 只改共享模型选择键 `OFFERSTEADY_CHAT_QWEN_MODEL`，保留已有独立快答/详细回答配置。模拟面试已有 `enable_thinking=false`；2026-10-08 代码核查发现资料摘要没有显式该参数，因此仅补齐 `enable_thinking=false`，保留摘要提示词、8 秒超时和提取式回退。不引入第二层 mock/summary 配置，避免不必要的分叉。
- 更新配置模板与长期文档，添加合成评测及路由回归。Python Settings 的提供方无关默认值不改；生产必须显式配置模型，不把这个部署选择硬编码到所有环境。
- 以国服运行容器镜像和完整现有环境为基线，仅在其摘要源码加入一个请求参数并生成 overlay 镜像；只切 backend 和 material-worker，保留所有非目标环境变量和容器属性。拒绝无条件从旧发布目录重新构建，以免覆盖后续功能。
- 真实模型测试仅使用合成简历、合成回答，不创建真实面试、不扣用户积分、不保存个人资料。复用既有服务端密钥，输出仅含耗时、模型与通过/失败检查。

## Risks / Trade-offs

- [新模型结构化 JSON 不兼容] → 用现有实际摘要、出题、报告适配器进行合成验证，失败不发布。
- [环境文件与运行容器有差异] → 对比完整环境但不输出密钥，只允许目标模型键变化；存在无关漂移则停止切换。
- [切换中断面试或资料任务] → 发布前检查普通/模拟活跃会话、近期准备/页面/音频及待处理回答、资料任务；有用户使用则保持线上不动。
- [健康检查失败] → 使用相同镜像与原配置恢复，仅保存配置备份，不删除卷或用户数据；旧模型回退仅为 10 月 10 日下线前的临时措施。
- [TTS 独立下线风险] → 明确此次不处理 TTS，最终交付保留该待办，不能以文本模型升级宣称全部下线风险解决。

## Migration Plan

1. 完成并校验规格；用户明确替换请求作为范围授权。
2. 更新模板、文档、合成评测与路由回归；运行本地相关测试。
3. 使用国服当前镜像和现有适配器验证 v4.1 的摘要、模拟出题/报告与非思考参数。
4. 空闲门禁通过后备份配置、最小更新并切换两项服务；健康检查和运行配置复核。
5. 核对非文本模型与快答/详细模型配置未变化、镜像仅包含审批的摘要参数补丁，记录验证；不自动推送 Git。
