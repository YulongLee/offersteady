## Why

手机端实时面试页目前沿用桌面双栏内容的纵向堆叠方式，导致对话、输入、操作和回答互相挤压，用户很难在有限视口中持续阅读答案。桌面伴随程序的旧图标同时包含白底和小字号文字，在 Dock、任务栏等小尺寸场景中呈现为方块且辨识度较低，需要随正式安装包一起更新。

## What Changes

- 为手机端实时面试页提供回答优先的独立工作区：回答与对话使用页签切换，不再同时堆叠成长页面。
- 将手机端手动输入、快答和截屏回答收敛到底部安全区内的紧凑操作栏，并在开始生成回答后自动回到回答页签。
- 精简手机端顶部，仅保留面试名称、收音状态和高频收音控制；结束面试等低频操作放入“更多”菜单。
- 移除手机端重复的底部“面试进行中”状态条，避免遮挡答案。
- 保持桌面 Web 工作区、回答链路、截屏链路、积分和后端接口行为不变。
- 为桌面伴随程序采用无文字、透明圆角、适合小尺寸展示的新图标，并通过新版本 macOS 与 Windows 安装包交付。

## Capabilities

### New Capabilities

- `mobile-live-interview-workspace`: 定义手机端回答优先、页签切换、底部固定操作栏和安全区适配行为。
- `companion-icon-release`: 定义桌面伴随程序图标的小尺寸可读性和跨平台安装包发布行为。

### Modified Capabilities

- `resizable-live-interview-workspace`: 将手机端从桌面内容的单列堆叠改为回答/对话按需切换，同时保持回答状态与历史位置不丢失。

## Impact

- Web：`apps/web/src/App.tsx`、实时面试组件、移动端样式与回归测试。
- Desktop：图标资源、Electron 打包配置、版本号、macOS/Windows 安装包及发布清单。
- 部署：Web 静态资源和桌面下载清单更新；不修改实时语音、回答、支付、积分或资料接口。
- 隐私：不新增音频、转录、截图或个人资料的采集与持久化。
