## Why

国际服用户需要从现有桌面助手打开浮窗并使用捕获保护。本次发布仅覆盖国际服。

## What Changes

- 在国际服 2.0.0 助手中加入英文桌面浮窗和系统窗口捕获保护。
- 复用国际服官网、收音、设备身份及面试流程。
- 发布通过验证的国际服 macOS arm64、macOS x64 和 Windows x64 安装包，保留旧版精确下载。

## Capabilities

### New Capabilities

- `global-floating-companion` 提供国际服浮窗、捕获保护与独立分发。

## Impact

目标为国际服助手及其下载入口。国服、支付、会员、数据和运行配置超出范围。
