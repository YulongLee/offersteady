## Why

The public topic hub now has a reviewed AI cluster, but Java backend, frontend, and algorithm candidates still see category summaries without dedicated preparation pages. Publishing the second technical cluster completes the approved first-stage topic tree without changing the interview product.

## What Changes

- Publish `/interview-questions/java-backend`, `/interview-questions/frontend`, and `/interview-questions/algorithms` as complete public guides.
- Cover language/runtime fundamentals, system design and diagnosis for Java backend; browser/runtime, accessibility and performance for frontend; and problem clarification, correctness, complexity and implementation for algorithms.
- Add primary sources, visible reviewer/dates, Article/Breadcrumb structured data, contextual links, sitemap/GEO entries, Nginx routes/CSP hashes, and deterministic 30-page checks.
- Preserve all authenticated product behavior and avoid leaked questions, invented projects, unsupported performance claims, or guaranteed interview outcomes.

## Capabilities

### New Capabilities

- `public-engineering-interview-topics`: Search visitors can prepare for Java backend, frontend, and algorithm interviews using complete, reviewable public guides.

### Modified Capabilities

None.

## Impact

- Three static public articles and associated discovery/release controls only.
- No backend, database, authentication, interview, audio, screenshot, material, billing, admin, or desktop changes.
