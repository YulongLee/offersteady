## Context

当前 10 个目标词分成四类：首页通用产品词、实时辅助词、程序员技术岗位词和价格词；“AI面试助手哪个好”属于比较意图，暂不具备可核实的竞品数据。现有静态 SEO 页面已能被抓取，但页面主题和内部链接仍有重复。

## Goals / Non-Goals

**Goals:**

- 为每个目标词设置一个主要承接 URL，并在首屏、Title、H1 或正文中自然表达。
- 让搜索引擎和 AI 系统能从初始 HTML 直接理解产品是什么、如何工作、适合谁和如何收费。
- 通过内部链接建立首页 → 功能页 → 技术专题/价格页的清晰关系。

**Non-Goals:**

- 不新增大量页面或修改现有 URL 结构。
- 不保证短期排名提升，不虚构绝对排名。
- 不修改动态价格、支付逻辑、用户数据或生产配置。

## Decisions

1. **首页承接通用词。** 保持首页承接 `AI面试助手`、`面试助手`、`AI面试辅助`、`面试AI`、`AI面试工具`；避免把首页改成关键词列表。
2. **实时页承接实时词。** 在实时页 Title、H1、首屏和流程段落中使用“实时面试辅助”和“AI面试实时回答”，首页只保留自然入口链接。
3. **技术页承接程序员词。** 将技术页的 Title、H1、首屏答案和专题链接集中到程序员/技术岗位场景，通用词只作为上下文。
4. **价格页承接价格词。** 使用“AI面试助手价格”自然表达，价格金额继续来自现有动态数据或登录后的权威页面，不在静态文案中猜测。
5. **GEO 采用直接问答结构。** 在公开说明中补充“面试稳是什么”“实时面试辅助如何工作”“程序员如何使用”“面试稳如何收费”等事实型答案，不新增 FAQPage 结构化数据。

## Risks / Trade-offs

- [关键词稀释] 过度删除通用词可能降低相关性 → 只减少重复主标题，保留正文语义和内部链接。
- [排名波动] 百度结果受时间、地域和设备影响 → 使用排名工具持续记录原始结果，不把一次查询作为结论。
- [动态价格过期] 静态页面复制金额可能失真 → 只描述计费逻辑，金额继续以产品实时页面为准。
