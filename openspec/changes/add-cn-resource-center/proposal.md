## Why

国服首页已经有“查看更多资源”入口，但目前主要承接零散的面试指南，不能系统承接用户搜索的技术排查问题。新增一个公开资源中心，可以把 API P95、容器内存、PDF 简历解析、麦克风权限和实时轮询等首批报告集中展示，形成“搜索问题 → 读技术报告 → 了解产品能力”的引流路径，同时不打扰现有面试、支付和登录流程。

## What Changes

- 新增国服公开资源中心目录页，展示报告标题、摘要、分类、更新时间和阅读入口。
- 新增首批 5 篇公开技术报告页面，内容来自现有产品问题与通用排查方法，不包含用户隐私、密钥或真实日志。
- 为目录和文章增加唯一标题、描述、H1、canonical、面包屑与文章结构化数据，并纳入公开 sitemap。
- 在首页“查看更多资源”中增加资源中心入口；现有面试指南、产品页、登录、支付和应用内路由保持不变。
- 文章使用静态公开页面，不依赖登录态，不读取业务 API，不显示动态价格或个人权益。
- 本轮不新增 CMS、不实现后台编辑、不接入推荐算法、不调整首页主体布局和业务服务。

## Capabilities

### New Capabilities

- `cn-resource-center`: 提供国服公开资源目录、文章详情、SEO 元数据、站内互链和静态发布契约。

### Modified Capabilities

- 无。现有登录、面试、资料、支付和桌面助手能力的需求不变。

## Impact

- 影响 `apps/web` 的公开静态内容、公开路由、首页资源导航和 sitemap 构建/校验。
- 新增文章源文件位于 `content/cn-resource-center-20261011/`，上线前需转为公开 HTML 资产。
- 不新增后端 API、数据库表、客户端权限或第三方密钥。
- 发布前需要本地构建、公开路由 200/404 检查、结构化数据检查、链接检查和移动端布局检查；本变更不包含线上部署。
