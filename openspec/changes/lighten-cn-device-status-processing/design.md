## Context

本轮用户已授权先开发、自测，晚上另行部署。实际国服 Backend 为 `c62df7dd…`，业务源来自 11 月 1 日，11 月 2 日仅热更新助手下载清单 `d7b106a6…`。以 `release-20261102.1` 封存的 232 份实际运行输入为基线；根目录另有尚未发布的笔试配套，不得混入候选。

最近五分钟普通 API P95 约 2.8 秒，多个控制路由同时变慢。后采样数据库连接建立约 18ms、轻查询约 1–4ms，不能归因当时的整个峰值。设备状态路由中同步仓库调用阻塞事件循环，且绑定验证和发布分别通过完整会话加载资料，是源码中可验证的问题。

## Goals / Non-Goals

**Goals:** 国服设备状态的同步业务工作脱离事件循环；两次权威会话检查均只读必要字段、不访问资料或写回会话；原状态事件/错误、绑定新鲜性及非目标功能保持。增加只含固定标签和数值的低比例私有观测，离线测试性能机制和合同等价。

**Non-Goals:** 本轮不部署或提交/推送，不改 Web、助手、Global、worker、收音、轮询频率、模型/Prompt/检索/预取/收费、连接池开关或上限、SQL schema/索引及运行依赖。不缓存用户/会话权限，不放宽门禁，不创建真实面试或生产压测，不承诺整体线上 P95 的降幅。

## Decisions

### 1. 单独的国服设备状态轻读入口

保留既有 `get_desktop_active_binding`、`_binding_is_active` 和 `publish_device_status` 的非目标调用语义。为国服设备状态发布添加专用服务入口，必要的私有解析/事件构造可共享，但原公开方法的默认行为保持。该入口的绑定检查与最终发布检查复用已有 `SessionService.get_control_state`，包括 owner/软删除/状态与 legacy 默认规则，不引入跨请求缓存。仍保留原先两个权威读取时点，避免合并后改变并发结束/删除行为。

手动码绑定按原顺序解析设备 ID、canonical ID、code fallback，检查 status、generation、heartbeat、preparing/live。最终 publish 的原 owner/存在校验保持；其原合同没有额外禁止 ended 状态，不能趁本轮改变。所有原 404/403/410 文案、错误码、payload 过滤与事件持久化保持。真正采集/业务授权及 Global 使用原完整读取。

### 2. 使用现有有界控制执行器

CN 路由将绑定解析和状态发布作为一个同步工作单元交给 `run_realtime_control`；请求格式及认证依赖保持，Global 沿原分支。不开新线程池、不改变现有上限或生命周期。同步业务失败直接传播，不重放；取消请求不能重复保存事件或将计时上下文泄漏到下一任务。现有执行器未配置时沿既有 `asyncio.to_thread` fallback。

### 3. 低比例且可精确解释的私有计时

为设备状态工作按固定约 1/20 的请求计数采样，使用常量字段与受限相位集合。工作线程内显式安装/清理 ContextVar（`run_in_executor` 不自动继承），记录自提交到工作开始的等待、工作总时长、DB connection acquisition、控制投影 execute/fetch、绑定仓库操作及事件保存。DB 获取计时在既有控制投影方法中只包围连接上下文进入，涵盖 connect/borrow，不修改提供器且不包含整个事务；execute/fetch 分开测量且 SQL 不变。绑定/事件仓库计时包含其自身序列化开销，不称为纯 Redis 网络时间。

只在选中工作作用域内启用钩子；其它路径及未采样时无日志、无跟踪状态增长。固定 logger 输出数值/固定成功失败状态，禁止用户/会话/设备/请求标识、SQL/参数、URL/DSN、权限码、异常文本、原始 payload。采样/计时/日志故障不得改变业务结果。时间使用单调时钟且非负有限；样本是工作单元观测，不包含此前认证依赖、HTTP 网络或浏览器呈现，相位存在嵌套，不能简单相加为总耗时。

替代方案：只加总耗时不能区分阻塞位置；全局代理所有仓库/SQL或调大连接池扩大风险；延长心跳间隔损害新鲜性，均不采用。

### 4. 实际基线加允许列表

从封存实际运行输入恢复独立 baseline，然后复制本轮必要文件到 candidate。保留未改输入逐字一致，特别是 `screenshot_answer.py`、下载清单、Settings、Prompt、模型、构建输入。候选完整 203 条 OpenAPI Schema 与实际封存等价；不以根目录全量构建替代生产基线。合成比较固定资料数和相同状态，验证完整读取/资料读取计数下降及慢仓库期间事件循环仍可调度；本地延迟不能直接换算生产收益。

## Risks / Trade-offs

- [轻读漏授权/删除/绑定 freshness] → 保持原解析顺序、逐次查询和错误，跨请求变化及并发最终检查回归。
- [共享线程池排队] → 不新增无界队列，保留配置与异常；采样等待可观测，事件循环阻塞回归。
- [观测泄露或污染结果] → 字段白名单、作用域 finally 清理、计时/日志失败隔离、并发/取消及隐私测试。
- [候选混入未上线功能] → 实际 232 输入基线、显式增量清单、全部未改 SHA 与完整 Schema 对比、独立审查。
- [真实瓶颈在其它路径] → 不承诺本轮解决全部高峰 P95；分项数据指导后续池/检索工作。
