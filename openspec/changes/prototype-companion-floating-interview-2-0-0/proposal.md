## Why

从本地原型推进到可连接现有国服的伴随程序测试包，以验证用户在同一个浮窗内完成登录、准备和使用实时面试的流程。

## What Changes

- 以国服已发布 1.3.6 助手为基线，保留原主窗口及其功能。本地 2.0.0 通过系统菜单栏或托盘的「桌面浮窗」入口打开。
- 浮窗直接加载国服受保护的面试入口，复用官网登录、账号管理、面试准备、绑定和实时工作台。
- 浮窗的面试准备页取消手动填写机器码，通过现有国服流程自动连接本机助手。
- 浮窗在切换普通窗口时保持置顶。保留移动和缩放，默认透明度为 0%，用户可调节。Windows 捕获保护保留接收端验证提示。
- 以正式签名、公证和音频权限验收流程生成 2.0.0 Mac 候选包。保持正式助手的权限身份，复用现有收音流程。
- Mac 本地版在原有「预览」和截屏流程中默认排除所有助手窗口，移除原型独立的「共享专用画面」。
- Mac 本地测试版默认请求主窗口和浮窗的系统捕获保护。会议软件的整屏共享效果需在接收端验证。
- Mac 浮窗可在整屏共享前临时收起。通过现有「桌面浮窗」菜单恢复同一页面。
- 候选包仅供本地验收，交付与官网发布分离。

## Capabilities

### New Capabilities

- `local-floating-interview-prototype`：使用独立的桌面浮窗连接现有国服面试功能。

## Impact

新增本地窗口控件及独立的官网视图。既有官网路由、后端契约和伴随助手采集仍按现有方式工作。
