## Why

国际服第一批可靠性补丁已上线，但资料处理重试与页面等待、回答断线后的服务端取消、管理员用户列表交互仍落后于国服已验证行为。用户已批准只开发这些非新功能改进并部署国际服。

## What Changes

- 补齐资料 Worker 的可重试状态处理，Global 资料页有界等待至终态，离开页面停止请求。
- 在回答流断开时取消未完成任务、释放预留，保留取消终态，禁止迟到结果覆盖。
- 国际服后台保留既有会员套餐逻辑，增加用户结果分页、列表注册时间、身份确认、搜索竞态保护和安全重试。
- 从各组件实际运行版本制作隔离候选，自测通过且面试/资料任务安全空闲后只切换相关国际服组件。

## Capabilities

### New Capabilities
- `global-second-batch-reliability`: 国际服资料、回答生命周期和会员后台的增量可靠性验收。

### Modified Capabilities
无；现有多语言、认证、Creem、套餐、模型和音频业务规则不变。

## Impact

Global Backend / Material Worker / Web / Admin；不需要桌面助手升级、数据库迁移、新供应商或新依赖。不新增联网回答或模拟面试，不部署国服，不修改历史资料/账本，不在本次删除磁盘文件或镜像。测试仅用合成用户和资料，线上只读验证，不调用付费模型或修改真实用户权益。
