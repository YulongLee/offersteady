## ADDED Requirements

### Requirement: 独立构建与发布
系统 SHALL 将管理前端作为独立构建和部署单元，并 SHALL NOT 把管理页面加入当前用户端生产路由或主构建包。

#### Scenario: 仅发布管理前端
- **WHEN** 管理前端发布新版本
- **THEN** 当前用户端静态资源、页面路由和功能行为保持不变

### Requirement: 生产默认关闭
系统 SHALL 通过服务端总开关控制管理 API，并通过独立域名和允许来源配置控制管理页面。

#### Scenario: 未配置管理环境
- **WHEN** 新环境没有设置管理功能开关、管理来源或 MFA 配置
- **THEN** 管理能力保持关闭且不降级为弱鉴权

### Requirement: 增量迁移
系统 SHALL 仅通过向后兼容的增量数据库迁移增加管理表和索引，SHALL NOT 修改现有业务数据的含义。

#### Scenario: 部署迁移但尚未开启后台
- **WHEN** 管理数据库迁移已经执行而功能开关仍关闭
- **THEN** 用户登录、支付、资料、面试和桌面链路继续按原行为运行

### Requirement: 无影响回滚
系统 SHALL 支持通过关闭管理域名和服务端开关回滚后台，同时保留审计数据并维持用户服务。

#### Scenario: 管理后台发生故障
- **WHEN** 运维关闭管理功能
- **THEN** 管理入口停止服务，用户端和公开 API 继续运行，已生成审计记录仍被保留

### Requirement: 管理端安全响应策略
系统 SHALL 为管理域名配置独立的 CORS、CSP、缓存和安全响应头，并 SHALL 禁止跨来源携带管理会话。

#### Scenario: 非允许来源请求
- **WHEN** 非配置来源尝试携带管理会话访问管理 API
- **THEN** 系统拒绝请求
