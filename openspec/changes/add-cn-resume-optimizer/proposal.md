## Why

国际服已提供简历诊断、优化、编辑及真实 Word/PDF 下载，用户现已明确要求将同等核心能力加入国服，并采用国服时间会员与积分钱包。国服用户应在保留原简历和面试流程的情况下，取得有依据、可核实、可下载的优化稿。

## What Changes

- 国服中文工作台新增简历优化入口，复用自有 ready 简历及可选目标岗位/JD；显示参考评分、证据、修改建议、待补充事实和可编辑优化稿。
- 支持原文/AI 初稿/用户编辑稿对照、真实 DOCX/PDF 下载及显式另存独立新简历；不覆盖原文件、Parser 产物或既有面试快照。
- 所有当前有效国服时间会员（含 1 天及现有管理员授予时间权益）按北京时间自然日免费 3 次；非会员及会员当日超额优化每次 100 积分。免费次数与模拟面试等其他功能独立；积分包不授予会员资格。
- 页面采用简洁单列操作流程，移除顶部费用/积分/重置时间大卡；会员权益及详细说明折叠呈现，仅付费开始时显示当次费用并明确确认。
- 服务端先报价并要求明确确认，免费额度变化不得静默改扣积分。创建、免费额度/积分预留、成功交付结算、失败/取消释放与幂等结果保持事务一致；编辑、下载、另存不重复收费。
- 迁移已验证的有界任务、事实约束、受控表格规范化、权限/删除传播及真实导出能力，使用国服中文独立 Prompt/evals，不影响实时面试执行池。
- 基于国服 Backend/Web 实际运行镜像开发和自测，保留已发布鉴权/状态读取、预取及其他功能；初次开发只交付本地可审查版本；2026-10-18 用户随后明确授权国服上线，现按 [生产追加规范](production-release.md) 发布已验收 20261018.2 增量。不更新国际服/助手/Admin，不提交推送 Git。

非目标：会员套餐定价、普通/模拟/笔试收费调整，钱包重构、自动投递、复杂模板市场、伪造经历、原排版完全复刻、外部共享链接、校园大使。生产发布仅限用户最新批准的国服 Backend/Web 增量，沿用 [生产追加规范](production-release.md) 的门禁、实际镜像与回退边界。

## Capabilities

### New Capabilities

- `cn-owned-resume-optimization-and-billing`: 国服自有资料、中文任务入口、北京时间独立会员日次数与 100 积分计费、原子幂等及退还边界。
- `cn-grounded-resume-review-and-export`: 中文参考评分、事实约束、原文对照、可编辑稿、真实 DOCX/PDF 及另存独立资料。
- `cn-resume-optimizer-isolation-and-verification`: 有界独立执行、权限和删除、实际国服基线、合成自测及后续发布授权边界。

### Modified Capabilities

无。复用现有钱包、会员、资料和鉴权能力，不改变它们既有产品规则。

## Impact

- 国服 Web 新中文页面/导航、API 客户端及报价/确认流程；Backend 新 optimizer 功能域、最小必要的路由/生命周期/资料删除接入及 additive 迁移。
- 复用已部署 Global 核心而显式隔离国服资格/时区/100 积分策略；不得将 Global 源整包覆盖国服实际镜像。
- 新增 `ai/prompts/` 中文 Prompt 与 `ai/evals/` 合成事实/语言/注入用例；现有面试 Prompt、模型和供应商参数保持。
- 任务主动保存用户输入/结果，页面须说明模型处理、保存与删除；不输出正文、联系方式、对象 key 或 provider payload 到日志。导出保持登录鉴权、私有且不可缓存。
