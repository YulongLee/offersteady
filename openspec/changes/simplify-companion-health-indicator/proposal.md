## Why

伴随程序在设备在线但尚未进入面试、或音频通道暂时静音时显示红色，用户容易误以为程序卡死或失灵。需要把内部连接阶段与面向用户的健康状态分离，让正常待机和正常面试保持一致的绿色反馈，同时保留真实故障的明确提示。

## What Changes

- 将伴随程序对外状态简化为正常绿色与故障红色两种视觉语义。
- 设备已登记且服务可达时，未绑定当前面试仍显示绿色正常状态。
- 音频通道已打开但当前静音时保持绿色，音量条继续反映真实信号且不伪造波动。
- 短暂、可自动恢复的重连保持绿色；只有确认的网络、权限或设备故障才显示红色。
- 桌面端版本从 1.2.11 升级到 1.2.12。
- 生成 macOS Apple Silicon、macOS Intel 与 Windows x64 的 1.2.12 发布产物，更新官网清单并部署生产下载入口。
- 不修改音频采集、实时传输、ASR、字幕、截图或面试绑定协议。

## Capabilities

### New Capabilities

- `companion-health-indicator`: 定义伴随程序面向用户的两态健康展示、静音状态及真实故障判定。

### Modified Capabilities

无。

## Impact

- Desktop renderer：健康状态派生、设备入口状态灯、音频来源状态灯和对应样式。
- Desktop tests：新增正常待机、静音、短暂重连和真实故障的回归场景。
- Desktop package metadata：小版本号更新为 1.2.12。
- Distribution：版本化桌面产物、OSS 对象和 Backend 下载清单。
- API、数据模型、音频与个人信息保存策略均不变。
