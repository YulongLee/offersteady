## Risks / Trade-offs

- Global上下文差异 → 显式函数允许清单/AST检查及Global回归；保留收费/语言/缓存/失败计数。
- 物理关闭迟到、队列满和重连 → 逻辑fence先行、旧对象引用、有界同步回退和排空；不承诺过载无等待。
- 索引过期/旧writer回退 → 原子重建、完整性和并发/精度/TTL实测；正常请求不能静默全扫。
- 发布中有新用户 → 每次切换与恢复重复全部门禁，不混跑writer；不声称零瞬时代理错误。
- 封版隐私与区域混淆 → 只封公开精确来源和脱敏证据，逐项扫描/校验，区域归属与实际组件绑定。
