## Why

国服管理后台已有服务端用户名/用户 ID 查询能力，但“用户与权益”页面只加载分页列表，积分调整只能从当前页下拉框逐个寻找，容易误选且操作低效。

## What Changes

- 增加提交式用户名模糊搜索和用户 ID 查询，保留服务端分页。
- 搜索结果逐行提供积分调整入口，确认界面展示身份、增减值和原因。
- 查询变化清除旧目标；处理过期响应、查询失败及重复提交，沿用管理鉴权、账本和审计。
- 2026-09-27 用户追加：在国服“用户与权益”列表及操作对象信息中显示真实注册时间（北京时间），复用现有 `created_at_ms`；已完成本地自测，随后用户明确授权部署国服。

## Capabilities

### New Capabilities
- `cn-admin-user-search`: 国服用户搜索与明确目标的积分调整体验。

### Modified Capabilities
无。

## Impact

仅国服 Admin 前端和测试，复用现有 `/api/v1/admin/users` 与积分命令。无数据库、用户端、桌面助手、AI 或国际服行为变更。原用户搜索版本已获授权并发布；2026-09-27 注册时间增量通过本地验证后获用户独立部署授权，只发布国服 Admin。新增用户统计问题仅做只读核查，不更改统计口径或线上快照。
