## Why

国际服仍运行 2026-09-22 基线，未包含国服已经验证的回答启动错误、截图异常恢复和简单回答独立完成修正，macOS Intel 正式助手清单仍为 1.3.0。用户于 2026-09-29 批准开发第一批四项并部署国际服。

## What Changes

- 在国际服实际运行版本上移植回答启动业务错误契约与截图异常日志修复。
- 简单回答完成后立即独立完成展示，详细回答失败不丢失已生成的简单回答。
- 补齐国际服 Intel macOS 1.3.2 正式安装包及清单，不引入尚未发布的桌面功能。
- 隔离候选、自测、无活动面试门禁及兼容回滚后，仅更新国际服相关服务。

## Capabilities

### New Capabilities
- `global-first-batch-reliability`: 国际服回答异常、分阶段完成、Intel 助手版本对齐和安全发布的回归契约。

### Modified Capabilities
无；保留现有国际服计费、认证、多语言与音频行为。

## Impact

涉及 Backend 回答及截图服务、国际服 Web 回答展示、共享回答协议及国际服桌面发布清单。无需数据库迁移。不得直接部署本地国服主工作区，不同步联网、模拟面试或国服积分规则，不变更模型、支付配置、Admin、国服服务和用户数据。
