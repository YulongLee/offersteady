## Why

详细回答目前只使用面试问题、用户材料和本地知识库，遇到需要实时事实、产品版本或行业背景的问题时，回答可能缺少最新依据。用户需要一个明确可控的联网回答入口，同时要有按次计费、会员权益、来源展示和失败回退，避免联网能力拖慢或破坏现有快答链路。

## What Changes

- 在实时面试回答操作区增加默认关闭的“联网回答”开关，并在开启后明确展示联网状态与费用规则。
- 仅在详细回答阶段执行联网检索；快答继续使用现有低延迟本地材料/知识库链路。
- 通过服务端配置的联网搜索工具调用 `deepseek-v4.1-flash`，把检索结果和来源交给详细回答模型，并返回可折叠的来源链接。
- 国内服非 7 天及以上有效时间会员按每次成功联网详细回答 20 积分预留—结算；失败、取消、超时或无有效结果时释放预留。
- 国内服 7 天、15 天、30 天及以上有效时间会员可免费使用联网回答；仍受会话、并发和频率限制约束。
- 联网服务不可用时回退到本地知识库详细回答，并向用户标明未使用联网资料；不影响普通快答。
- 对搜索问题和发送给第三方搜索/模型服务的上下文做最小化处理，默认不发送完整简历、原始音频、截图或不相关材料。
- 增加服务端联网配置、计费幂等、来源溯源、权限检查和 AI 评测回归案例。

## Capabilities

### New Capabilities

- `web-grounded-interview-answers`: 定义联网开关、详细回答检索、来源、回退、隐私和可观测行为。
- `web-answer-entitlement-metering`: 定义 20 积分预留/结算、7 天以上会员免扣、失败释放和幂等语义。
- `live-interview-web-mode`: 定义实时面试页中联网开关与答案展示的用户交互。

### Modified Capabilities

无。当前仓库没有可用于增量修改的已归档实时回答能力 Spec；联网模式作为新能力与现有回答接口兼容接入。

## Impact

- Web 国服实时面试页的回答操作栏和答案展示组件。
- FastAPI live-answer 请求/响应模型、ChatService、模型网关和计费服务。
- 新增可替换的联网搜索适配器与服务端环境变量；搜索密钥不得进入浏览器。
- 新增来源元数据持久化/返回字段、日志脱敏和搜索耗时监控。
- 新增后端单元/集成测试、前端交互测试和 `ai/evals/` 联网回答评测样例。
- 部署前需要确认阿里云百炼 Responses API 的地域、模型权限和生产密钥配置；国际服暂不复用国内积分体系。
