## Why

实时面试中用户通常把注意力放在题目或会议窗口，切回网页点击“截屏回答”会打断操作节奏。桌面助手需要提供可配置的全局快捷键，在当前面试有效连接时直接复用现有截屏回答链路。

## What Changes

- 在桌面助手“屏幕捕捉”区域增加截屏回答快捷键设置，提供安全预设、关闭选项和注册冲突提示。
- 将快捷键偏好持久化到本机助手数据目录，重启后保持不变。
- 仅在当前设备存在有效 live session 绑定时允许快捷键创建截屏回答任务，未连接、准备中或已结束时不截屏。
- 快捷键触发后复用现有整屏捕获、上传、视觉模型回答和失败反馈链路。
- 网页面试页同步当前 session 中由助手快捷键完成的截图回答，避免形成独立答案孤岛。
- 保持网页“截屏回答”按钮、实时语音、资料、RAG 和计费接口的既有行为不变。

## Capabilities

### New Capabilities

- `desktop-screenshot-shortcut`: 定义助手快捷键配置、全局注册、live session 门禁、截图任务触发和网页结果同步。

### Modified Capabilities

无。

## Impact

- 桌面端 Electron 主进程、preload、助手设置界面和本地偏好文件。
- 后端 Screenshot Answer Service 新增设备授权的快捷键任务入口。
- 网页实时面试页新增当前 session 快捷键截图结果同步。
- 不新增第三方依赖，不修改音频采集、模型配置、资料或数据库结构。
