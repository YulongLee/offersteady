## Context

国服今日笔试多屏功能已上线并独立验收。国际服上次发布为Global resume optimizer，拥有独立英文Web、Global Commerce、UTC权益及鉴权/预取优化；Git混合工作区不能代表目标当前镜像。用户本轮明确授权同步今天功能、自测后部署国际服。

## Goals / Non-Goals

**Goals:** 默认关闭的英文多屏笔试、最多4张有序采集/移除/一次批答、无采集费用、沿用Global一次截图权益；保留全部无关线上能力并安全部署。

**Non-Goals:** 不改Global会员/模拟面试/简历次数、积分/Creem/价格，不同步国服简历研发/回退，不改模型/Prompt/DB/依赖/配置，不发布CN/Admin/worker/助手，不Git提交推送，不创建生产测试会话、处理真实用户资料或生产压测。

## Decisions

1. 读取并冻结实际Global Backend/Web全清单、完整OpenAPI、有效Settings摘要和非目标归属，下载仅源码与公开静态至独立artifact目录。替代方案Git整包覆盖可能回退独立权益或优化，故拒绝。全部生产私有环境留服务器。
2. 以实际Global截图文件为祖先逐方法应用CN增量，尽量限定6个源码；原Global结算、会话语言/授权和其他方法不变并逐方法审查。仅采集默认false；批答同用户、active written、最多4、有效未消费图；Redis/内存原子幂等、取消终态及TTL清理复用CN已验证方案。
3. Web使用实际Global英文静态与source的最小可核对overlay。保留原单图与普通面试模块，written才显示英文开关/拆分按钮；复用原React/context/adapter实例和Global路由，不引入国服积分文案。原hash资源不覆盖，必要模块URL改变精确记录，全部旧文件保留。
4. 截图仅短期内存；浏览器只存ID/标签；无个人资料进入测试，无真实截图/音频写诊断。AI输出继续作为建议，原图顺序传同一次视觉网关，模型/Prompt不变。首选禁网合成完整ASGI/网关契约，不重复调用真实模型；若确需提供方联调仅允许独立最多1次、两张合成图、无重试/业务写入，并单独记录。
5. 基于固定实际镜像只COPY批准输入，无依赖/迁移/环境变动。复用实际Global原完整Compose和冻结上下文，加本轮固定镜像overlay；保留原6类用户任务保护并补财务/实际TCP只读保护。所有非零/未知延期或停止，切换/恢复均不结束面试或清理活动。
6. 复用已修正的公开URL映射，不把内部HTML文件名当地址。最终仍要求200/SHA或预期匿名401/no-store。独立verify后至少180秒聚合错误观察，只报告聚合，不输出原始日志。

## Risks / Trade-offs

- 国际服与CN源码不同 → 按实际源逐方法合并，比较未批准AST/字节与区域回归；不整文件替换。
- Web模块/翻译/上下文不同 → 以实际编译模块做页面与adapter联调，英文/原功能入口核对。
- 多图增加模型耗时 → 保持4图/原大小限制、可取消，不进行生产压测。
- 单进程暂存与重启丢图 → 保持原拓扑与TTL，过期真实提示重截，不引入跨实例架构。
- 真实用户活跃 → 只延期，不人为结束；新鲜基线/候选/上下文漂移停止，不绕保护。

## Migration Plan

冻结actual基线 → 最小源/英文静态实现 → 合成测试/审核/strict → 固定候选实际探针 → 新鲜门禁preflight → 紧邻重复门禁Backend/Web切换 → 独立完整/公开验收 → 180秒脱敏观察 → 保存恢复材料和文档。已部署则验证，不重复重启；可恢复错误仅在本轮归属及空闲再次证明后恢复固定旧镜像，用户数据/账本不回滚。
