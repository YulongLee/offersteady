## Why

Global 求职者已在资料库上传简历，但目前无法在站内获得有依据的简历诊断、可编辑优化稿和可投递附件。用户已批准先开发并自测国际服，国际服验证后再另行决定国服发布；本轮将简历优化接入准备流程，并保护正在进行的面试。

## What Changes

- Global 工作台新增英文 Resume Optimizer 入口，并复用现有简历上传/选择；支持可选目标岗位和 JD，没有 JD 时明确给出通用诊断。
- 对用户自己的指定简历版本提供参考总分/维度分、原文依据、修改建议和结构化优化稿；明确分数不是录用概率，未知经历、技能和成果数字使用待补充提示而不虚构。
- 支持原文与优化稿对照、用户编辑、保存为独立新简历，以及下载真实 Word 和 PDF 附件；保留原简历和现有面试材料快照。
- 新增独立有界后台任务，处理排队、超时、失败、重试与删除；服务端持续校验账号归属和源资料删除状态，不记录简历/JD/Prompt 正文。
- 国际服只使用时间会员：所有有效付费时间会员（含 1 天套餐）按 UTC 每日免费优化 1 次；非会员提示升级会员，当日超额提示次日再试。失败/取消退还创建日次数，编辑、导出和另存不再占次数；不引入积分、新钱包或额外付费入口，其他 Global 权益保持。
- 以国际服实际运行镜像和 Web 构建为基线测试并增量发布，保护已有功能、鉴权/状态读取与预取优化；国服、Admin 和伴随程序不发布。

非目标：自动投递、录用概率预测、伪造经历、外部简历共享链接、复杂模板商城、国服同步、校园大使活动、现有支付规则调整。

## Capabilities

### New Capabilities

- `global-owned-resume-optimization`: Global 自有资料输入、任务生命周期、权限、访问资格和删除边界。
- `grounded-resume-review-and-export`: 有依据的参考评分、事实约束、可编辑优化稿、另存资料与真实 DOCX/PDF 导出。
- `global-resume-optimizer-safe-release`: 有界任务资源、国际服隔离、测试与保护活跃用户的增量发布。

### Modified Capabilities

无。现有原文件下载、材料选择、面试快照和账本规则保持。

## Impact

- Global Web 新页面/导航和新 API 客户端；不改中文 Web。
- Backend 增加独立 module、schema、service、repository/迁移、后台任务与导出适配器，只有必要的注册、配置和资料删除钩子接入既有层。
- `ai/prompts/` 新增独立英文简历诊断/优化 Prompt，`ai/evals/` 新增合成事实约束评测；不得复用或调整实时面试 Prompt。
- 结果包含个人资料，持久化只为用户主动创建的任务/草稿与另存操作；导出按账号授权返回附件，不暴露对象地址；源删除与任务删除需真正清理派生内容。
- 所有新依赖/迁移先核对实际国际服组件；仅允许经自测与门禁的国际服 Backend/Web 发布，不提交推送 Git。
