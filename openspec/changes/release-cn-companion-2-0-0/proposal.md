## Why

用户于 2026-11-14 授权更新部署国服伴随程序 2.0.0。三平台候选已完成本地封装，Mac App 和 DMG 公证通过；既有 Zoom 浮窗捕获限制、Windows 未签名及实体验收缺口已向用户说明。

## What Changes

- 发布国服 2.0.0 三平台安装包及下载清单；基于实际国服 Backend 镜像增加一处下载列表隐藏标识处理以保留旧精确下载，同时不发布其他业务改动或国际服。
- 从即时实际运行基线准备、保护并验证单清单增量，不使用旧版本发布记录代替当前状态。
- 复用有条件不可变对象和只读业务门禁，准备经验证的 Backend 受控切换及回滚；保留历史下载及已进行用户工作。
- 记录实测范围和未完成的真实硬件、音频及 Zoom 验收，绝不宣称全面隐身或 Windows 已签名。

## Capabilities

### New Capabilities

- `cn-companion-2-0-0-publication`: 三平台对象、国服清单切换与完整验证。

### Modified Capabilities

无。

## Impact

影响国服下载安装包、下载清单及 Backend 下载列表处理；可能需要在业务空闲时重建 Backend，不改模型、数据或其他业务功能，不提交 Git。
