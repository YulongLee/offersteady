## Context

Electron 主窗口当前固定为 `780 × 650`，最小高度为 `610`。主页面移除常驻预览行后，主要内容约占 500 像素高度，旧窗口尺寸在底部留下约百余像素空白。

## Goals / Non-Goals

**Goals:**

- 默认打开时窗口高度贴合品牌栏、三项设备控制、连接管理和页脚。
- 保留少量视觉呼吸空间，内容增长时可通过现有页面滚动访问。
- macOS 和 Windows 使用一致的窗口内容策略。

**Non-Goals:**

- 不动态监听每个 DOM 变化并持续调整原生窗口。
- 不改变窗口宽度、控件尺寸或采集业务逻辑。

## Decisions

1. 将原生窗口默认高度从 650 调整到 540，最小高度从 610 调整到 500。相比根据 DOM `scrollHeight` 自动 resize，固定紧凑基线更简单稳定，不会在状态提示变化时造成窗口跳动。
2. 保留 renderer 的 `min-height: 100vh` 和 `overflow-y: auto`。窗口内容超出时滚动，不裁切连接管理或后续错误提示。
3. 使用源代码契约测试锁定默认和最小高度，避免移除界面元素后再次遗留过大窗口。

## Risks / Trade-offs

- [较长状态提示使内容超出默认高度] → 页面保留纵向滚动，用户仍可访问全部控件。
- [不同平台标题栏占用高度略有差异] → 预留约 20–40 像素底部空间，并将最小高度设置为 500 而非内容的绝对极限。
