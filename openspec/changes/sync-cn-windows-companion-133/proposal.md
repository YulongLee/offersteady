## Why

国服 Mac 助手已发布 1.3.3；上一轮仅修复 macOS 授权，因此 Windows 留在 1.3.2。用户现在明确要求同步发布 Windows 1.3.3。

2026-10-02 后续范围修订：用户要求保留原设计并重新打包。保留变更标识作历史追溯，目标版本改为 1.3.4，与原设计修正版 Mac 包一致。本次只恢复本地构建与验收，线上发布仍暂停。

三份安装包交付后，用户明确要求线上更新。本次与 Mac 1.3.4 一起激活国服完整清单；国际服不变。此前“只更新 Windows、保留 Mac 条目”仅适用于最初单独补发计划，当前以用户批准的三平台同步发布为准。

## What Changes

- 从已发布 1.3.3 源码加原设计恢复补丁构建国服 Windows 1.3.4 x64 NSIS 安装包，验证版本、入口、包结构和校验值。
- 只更新国服 Windows 下载条目，保持两份 Mac 安装包及国际服版本不变。
- 沿用既有签名状态，不把未签名 Windows 包描述为已签名；明确 Windows 实机验证限制。
- 不调整业务逻辑、音频路由、设备身份、计费或采集数据保存规则。

## Capabilities

### New Capabilities

- `cn-windows-companion-133-publication`: 可验证、可回退的 Windows 1.3.3 补发。

### Modified Capabilities

None.

## Impact

Windows 构建产物、国服下载清单、发布记录与回归验证；无需业务后端重新部署或重启。不增加音频、截图或个人资料的采集与存储。
