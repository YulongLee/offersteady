## Context

国服 Mac 1.3.3 已发布于 `7fe83aa`；Windows 仍为 1.3.2。既有 Windows 安装包为运营授权分发、尚未 Authenticode 签名的 NSIS x64 包。本次授权补发 Windows，不重做 Mac 权限修复，不发布国际服。

## Goals / Non-Goals

**Goals:** 按后续用户要求将本地三种平台包对齐为原设计修正版 1.3.4；安装入口、设备身份、协议和能力与已确认行为保持兼容。发布时下载真实可用且可回滚。

**Non-Goals:** 不新增 Windows 功能、签名证书或采集权限机制，不升级依赖，不部署其他未发布功能，不修改服务器业务代码或重启服务，不保留真实音频/个人数据。

## Decisions

- 采用已发布 1.3.3 分支的现有 Windows 构建链，而非主工作区全部代码，防止引入未发布功能。
- 使用缓存中相同版本 Electron Windows x64 运行时并检查 PE 架构，NSIS 安装器仍定位 OfferSteady.exe；不把 macOS 权限面板显示在 Windows 上。
- 正式分发状态与签名证据分离，保留 `local-development` / 非公证技术状态，不虚报签名。
- 只原子替换国服清单，Mac 条目逐字段保留；同步当前镜像的清单层以支持未来重建，不重启业务服务。替代方案“整套后端重建部署”因与任务无关且风险更大而不采用。

## Risks / Trade-offs

- [没有 Windows 实机] → 自动化回归、安装器结构/PE/打包入口检查、远端完整哈希校验；明确安装和麦克风/系统声音实机验收仍由用户完成。
- [未配置 Windows Authenticode 证书] → 保留事实签名状态，提示可能出现未知发布者/SmartScreen，不关闭系统安全功能。
- [现有版本门禁会要求 Windows 新面试升级] → 发布前确认没有 live 面试，明确用户升级后再绑定；不添加采集中断逻辑。
- [清单部分发布或并发部署] → 保留备份，校验旧容器、镜像和清单标识，上传验证完成才切换。

## Migration Plan

本轮只重新打包 1.3.4 并进行本地验收，不执行后续上传或线上清单切换。既有变更标识中的 133 保留作追溯；下述原始发布步骤在重新获得上线确认前保持待办。

后续用户已明确授权线上更新：与 `fix-macos-microphone-permissions` 的两份 1.3.4 Mac 包一次发布。所有安装包远端完整哈希验证通过才激活国服完整清单；备份原清单和当前镜像，部署使用当前镜像加清单层，容器不重启。国际服条目继续逐字段核对不变。

标准自测和构建；检查 NSIS 包及其中 1.3.4 运行文件；备份并上传；核验远端完整哈希；无进行中面试时更新国服清单；验证下载、健康、Mac/国际服不变；保存 Git 发布记录。回滚只恢复 Windows 补发前清单和对应镜像标签，保留届时已发布的 Mac 条目。
