## ADDED Requirements

### Requirement: 展示实时支付经营摘要
系统 SHALL 按 `Asia/Shanghai` 当前自然日从权威订单数据生成实时支付摘要，并 MUST 分开展示已入账、待确认、回调异常和已关闭订单的数量与金额、统计口径及生成时间。

#### Scenario: 查看今日实收
- **WHEN** 具备支付或可观测权限的管理员打开运营总览
- **THEN** 系统直接汇总当日 `paid_at_ms` 且状态为 `paid` 的订单金额，并将其标记为实时值而非日结趋势快照

#### Scenario: 支付宝已收款但本地未入账
- **WHEN** 某订单收到支付成功通知但通知校验失败且本地状态仍为待确认
- **THEN** 实时摘要不得把它计入已入账金额，并 SHALL 在回调异常或待对账金额中展示

#### Scenario: 实时查询失败
- **WHEN** 实时支付摘要查询超时或数据库暂时不可用
- **THEN** 管理端显示可重试的不可用状态且保留历史趋势和其他管理功能

### Requirement: 提供脱敏支付通知诊断
系统 SHALL 分别记录并展示通知签名、AppID、Seller ID/PID、订单、金额和交易状态的安全校验结果，且 MUST NOT 存储或返回通知原文、密钥、完整渠道交易号或用户支付账号。

#### Scenario: Seller ID 不匹配
- **WHEN** 支付宝通知签名有效但通知 Seller ID 与配置的签约商户不一致
- **THEN** 系统拒绝入账并记录 `seller_identity_mismatch` 安全分类，而不是仅显示笼统的签名失败

#### Scenario: 历史事件没有拆分诊断
- **WHEN** 管理员查看迁移前只保存综合校验结果的回调事件
- **THEN** 页面将未知维度显示为“历史未采集”且不得推断为通过或失败

### Requirement: 仅通过渠道权威结果恢复订单
系统 SHALL 允许具备 `payments.reconcile` 权限且完成近期 MFA 的管理员逐笔触发支付宝权威查单，并 MUST 仅在响应签名、订单号、金额和支付状态全部通过时幂等确认订单与发放权益。

#### Scenario: 权威查单确认成功
- **WHEN** 支付宝返回已支付、响应验签通过且订单号和金额与本地订单一致
- **THEN** 系统原子地把订单确认为 `paid`、追加对应积分或会员权益、记录审计，并使实时实收摘要立即包含该金额

#### Scenario: 对账请求被重复提交
- **WHEN** 同一订单的对账操作因重试或重复点击再次执行
- **THEN** 系统返回已对账结果且不得重复发放积分、会员时长或重复累计金额

#### Scenario: 渠道结果不可信
- **WHEN** 响应验签失败、渠道报告未支付、订单号不符或金额不符
- **THEN** 系统保持订单未入账并返回安全诊断，不提供绕过验证的手工成功操作

### Requirement: 显示支付渠道真实验收状态
系统 SHALL 将静态配置校验、用户端开关、最近通知校验和最近权威查单分别展示，并 MUST NOT 将密钥格式正确等同于真实支付链路已验收。

支付宝 Seller ID/PID MUST 在静态配置阶段校验为以 `2088` 开头的 16 位纯数字。格式不符合时渠道 MUST NOT 进入可启用状态，页面 SHALL 说明应从支付宝商户平台复制签约 PID，而不是应用 ID、支付宝账号或商户订单号。

#### Scenario: 配置格式正确但通知失败
- **WHEN** 渠道配置通过静态校验且已开启，但最近支付成功通知的身份或签名校验失败
- **THEN** 支付设置显示“用户端已开启、真实通知验收失败”及安全错误分类和处理提示

#### Scenario: 渠道真实验收通过
- **WHEN** 内部真实订单完成下单、权威通知或查单、金额核对及权益到账
- **THEN** 系统显示最近验收成功时间和方式，不暴露密钥或完整交易号

#### Scenario: Seller ID 不是签约 PID
- **WHEN** 管理员填写的 Seller ID 不是以 `2088` 开头的 16 位纯数字
- **THEN** 系统拒绝把配置标记为可启用、保持渠道关闭，并显示获取正确签约 PID 的处理提示

### Requirement: 保护实时财务查询和操作
系统 MUST 对实时摘要、回调诊断和对账操作实施权限、时间范围、分页、超时、限流、审计和幂等控制。

#### Scenario: 无权限用户访问财务摘要
- **WHEN** 普通用户或缺少对应管理权限的管理员请求实时支付数据或对账
- **THEN** 系统拒绝访问且不返回金额、订单或诊断信息
