## Why

已登录用户进入面试稳时，公开状态加载与会话恢复并发，失败分支会短暂露出“后端页面状态无法加载”，造成明显闪屏。设置页的回答字号目前只是静态控件，深色界面也缺少更明亮的可选外观，无法满足不同屏幕和阅读习惯。

## What Changes

- 已存在登录会话时只由会话恢复流程加载受保护状态，在身份和数据确认完成前使用无可见文案、与当前主题一致的静默过渡，不短暂渲染后端错误页、技术性加载提示或未登录内容。
- 让“回答字号”成为真实、即时、刷新后仍保留的显示偏好，并作用于实时面试回答正文、列表、代码和公式。
- 在设置页新增“界面主题”，提供当前深色主题与高亮浅色主题，切换后立即作用于应用和实时面试工作台并持久化。
- 在 React 首次渲染前应用已保存主题，避免刷新时先黑后亮；非法或损坏偏好安全回退到默认值。
- 不修改后端接口、用户业务数据、桌面助手或面试内容。

## Capabilities

### New Capabilities

- `protected-web-state-loading`: 规定已登录用户进入 Web 应用时的状态恢复所有权、加载占位和错误展示时机。
- `web-appearance-preferences`: 规定回答字号和深色/高亮浅色主题的设置、即时生效、持久化与安全回退行为。

### Modified Capabilities

无。

## Impact

- 主要影响 `apps/web` 的应用初始化、设置页、实时回答区域和主题样式。
- 新增仅保存在当前浏览器 `localStorage` 的非敏感显示偏好，不同步账号，不写入 Backend。
- 不需要数据库迁移，不需要重新编译或发布桌面助手。
