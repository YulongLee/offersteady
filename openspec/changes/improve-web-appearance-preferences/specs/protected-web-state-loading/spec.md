## ADDED Requirements

### Requirement: 已登录状态只有一个初始化加载所有者
系统 MUST 在浏览器存在登录会话时只通过会话恢复流程加载受保护应用状态，MUST NOT 同时启动会产生未授权错误的公开状态加载。

#### Scenario: 有效会话进入应用
- **WHEN** 用户带有有效保存会话打开 `/app` 或实时面试地址
- **THEN** 系统保持中性加载界面直到身份和应用状态恢复完成，且不会短暂显示后端错误页、登录页或无权限内容

#### Scenario: 没有保存会话访问公开页面
- **WHEN** 用户没有保存会话访问首页或登录页
- **THEN** 系统加载公开状态并正常显示公开页面

### Requirement: 初始化错误只在最终失败后展示
系统 SHALL 区分进行中的会话恢复与最终加载失败，只有在没有可用应用状态且负责初始化的请求最终失败后才展示后端集成错误。

#### Scenario: 会话恢复请求较慢
- **WHEN** 会话恢复仍在进行且应用状态尚未返回
- **THEN** 系统继续显示中性加载状态，不将并发或中间请求结果渲染为错误

#### Scenario: 初始化最终失败
- **WHEN** 唯一初始化流程失败且没有任何可用应用状态
- **THEN** 系统显示可理解的加载失败说明和检查服务入口
