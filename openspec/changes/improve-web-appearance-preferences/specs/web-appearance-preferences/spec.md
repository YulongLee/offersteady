## ADDED Requirements

### Requirement: 回答字号设置真实作用于实时回答
系统 SHALL 在设置页提供标准和较大两档回答字号，并 MUST 将选择即时应用于实时面试回答正文及其 Markdown 列表、代码和公式内容。

#### Scenario: 切换到较大字号
- **WHEN** 用户在设置页把回答字号从标准切换为较大后进入或返回实时面试
- **THEN** 回答正文和结构化内容使用较大字号，控制按钮、导航和对话转写字号不被整体放大

#### Scenario: 刷新后保留字号
- **WHEN** 用户选择较大字号后刷新浏览器
- **THEN** 系统在实时回答首次绘制时继续使用较大字号

### Requirement: 用户可选择高亮浅色主题
系统 SHALL 在设置页提供深色和明亮两种界面主题，并 SHALL 在选择后即时应用于受保护应用和实时面试工作台的背景、卡片、输入框、文字和边界颜色。

#### Scenario: 选择明亮主题
- **WHEN** 用户把界面主题切换为明亮
- **THEN** 应用和实时工作台使用高亮浅色表面及深色正文，同时保持品牌色、状态色和交互控件可辨识

#### Scenario: 刷新明亮主题页面
- **WHEN** 用户在明亮主题下刷新或直接打开实时面试地址
- **THEN** 系统在 React 页面首次绘制前应用已保存主题，不先闪现深色页面

### Requirement: 显示偏好安全持久化与回退
系统 MUST 只在当前浏览器保存非敏感显示偏好，MUST NOT 将偏好混入面试内容或服务端业务状态，并 SHALL 在存储不可用、JSON 损坏或取值未知时使用安全默认值。

#### Scenario: 偏好存储损坏
- **WHEN** 保存的显示偏好无法解析或包含未知字号与主题
- **THEN** 系统使用标准字号和深色主题继续运行且不阻断页面加载

#### Scenario: 浏览器禁止本地存储
- **WHEN** 读取或写入 localStorage 抛出异常
- **THEN** 当前页面仍能即时切换显示偏好，刷新后允许回退默认值
