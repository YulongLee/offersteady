## Context

公开首页已有多栏页脚和最底部法律信息栏，目前包含版权及 ICP 备案号。公安机关官方指引要求网站通过公安联网备案后，在首页底部显著展示公安联网备案号。此次只补充已确认的公安备案信息，不改变首页主体结构。

## Goals / Non-Goals

**Goals:**

- 在首页最底部持续展示“浙公网安备33010602014812号”。
- 允许访客通过备案号进入公安机关互联网安全管理平台的对应记录。
- 保持现有 ICP 备案、版权信息、主题和响应式布局。

**Non-Goals:**

- 不新增后端配置或管理后台字段。
- 不改变用户协议、隐私政策或其他页面。
- 不代替备案主体核验，也不推断用户未提供的备案信息。

## Decisions

1. 公安备案号放入现有 `public-footer-legal` 最底栏，与 ICP 备案并列。这样满足首页底部可见性，又不会引入新的页脚层级。备选方案是放入折叠的“查看更多资源”，但折叠后不够显著，因此不采用。
2. 链接使用公安备案平台的记录查询地址，并带入 `recordcode=33010602014812`。链接采用新窗口和 `rel="noreferrer"`，与现有 ICP 外链策略一致。
3. 法律信息栏增加一个内部链接容器，桌面端横向排列两个备案号，窄屏自动换行；不改变整个页脚的字号、颜色和品牌视觉。
4. 同步维护 `public-facts.json`，使可抓取的公开产品事实与页面内容一致。

## Risks / Trade-offs

- [公安备案平台未来调整查询 URL] → 将 URL 集中记录在公开事实文件并用回归测试锁定，后续可单点更新。
- [小屏下两个备案号过长造成拥挤] → 备案链接容器允许换行，并沿用移动端纵向法律栏。
- [备案编号录入错误] → 测试精确校验用户提供的完整编号和 `recordcode`。

## Migration Plan

部署纯前端静态变更，无数据迁移。若上线后发现备案信息有误，可回滚该前端提交，不影响登录、面试或后端服务。

## Open Questions

无。备案号已由用户明确提供。
