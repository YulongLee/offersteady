## Why

笔试中的长题目可能分布在多个屏幕或滚动页面。现有“截屏回答”每次截取后立即生成，无法将同一题的多张图片一起理解。用户已明确要求在当前国服封版上增加可切换的多屏回答流程。

## What Changes

- 仅在笔试工作台顶部增加默认关闭的“多屏回答”开关。
- 开启时将原操作拆成“截屏”和“回答”：连续截取所选屏幕的当前画面，按截取顺序暂存最多4张（沿用现有服务端上限），点击回答后作为一次任务合并理解、流式输出。
- 展示待提交图片数量和移除入口；截图阶段不生成、不计费；回答沿用一次现有截图回答结算规则。
- 关闭、离开、结束或页面被替代时清理待提交截图；失败、重复点击和过期提供真实状态，不静默重复生成。
- 关闭时保留原单图截屏即回答。首阶段已完成本地实现、自测和预览；用户随后明确授权“上线国服吧。我这边测试下”，现仅发布国服Backend与Web的本功能增量，不操作真实用户会话。

## Capabilities

### New Capabilities

- `written-multi-screen-answer`: 笔试多屏模式、暂存捕获、顺序多图提交、隔离和资源清理。

### Modified Capabilities

无。现有笔试及截图能力的已批准基线见 `add-written-exam-mode` 与 `establish-screenshot-answer-service` 历史变更；本次为默认关闭的可选增量。

## Impact

国服 Web 的笔试工作台、截图 adapter 和 Backend 截图请求编排。新增兼容字段与多图回答入口；复用现有桌面捕获/上传、图片暂存、视觉网关、事件流和结算，不增加数据库表或依赖。图片仅按现有短期内存生命周期暂存，不写客户端持久存储或诊断正文；输出仍为AI建议。模拟面试、普通面试、简历优化、国际服、助手分发和既有收费规则不在范围。
