# OfferSteady 价格夯拉评估短视频

竖屏 52 秒中文视频，只比较国产 AI 面试助手的公开价格、临时单场最低套餐、用量规则和定价透明度。

## 交付文件

- `out/offersteady-hangla-price-cn.mp4`：旁白 + SFX + BGM
- `out/offersteady-hangla-price-cn-nobgm.mp4`：旁白 + SFX，无 BGM
- `voiceover-script.txt`：最终旁白
- `design-spec.md`：价格来源、事实口径和分镜
- `verification.md`：技术验证记录

## 重新渲染

```bash
npm run render
npm run render:nobgm
```
