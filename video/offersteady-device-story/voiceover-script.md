# 中文旁白脚本

MiniMax speech-2.8-hd，male-qn-jingying，中文男声。按八个镜头分段生成；不改变画面时间线。

| 开始秒 | 旁白 |
|---|---|
| 0.35 | 电脑上的面试，手机上的思路。 |
| 5.30 | 先在电脑安装并打开面试稳助手，完成权限设置。 |
| 12.30 | 手机登录同一账号，打开面试网页，输入电脑连接码。 |
| 20.30 | 开始面试，电脑接收声音，手机查看实时对话。需要回答时，点一下快答。 |
| 29.30 | 结合本场资料，先看简短思路，再展开详细回答。 |
| 36.20 | 也可以用平板，换一块大屏查看。 |
| 41.15 | 习惯电脑操作，就直接在电脑上看。 |
| 45.20 | 面试稳。电脑运行，在哪看，由你选择。 |

生成接口：[MiniMax 同步语音合成文档](https://platform.minimaxi.com/docs/api-reference/speech-t2a-http)。凭据仅通过隐藏输入传入生成进程，未写入工程文件。
